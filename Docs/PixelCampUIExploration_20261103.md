# IMAO 像素营地 UI 探索

本次用户要求：新建分支，大胆探索像素艺术与游戏场景式模块，以 HTML 展示方案。

- 分支：`codex/imao-pixel-ui-exploration`
- 入口：[`design/pixel-camp/index.html`](../design/pixel-camp/index.html)，直接双击即可离线浏览，无依赖安装、无外部素材请求。
- 性质：独立、可抛弃的视觉探索原型；并非 WinUI 重构，也不是已批准的生产设计。

## 设计选择

采用「漂泊者营地」：苔绿与奶油纸色作为应用外壳，暖橙强调行动，原生 Canvas 像素几何绘制场景。中文优先使用系统可读字体，英文编号用等宽字，像素质感由画面、硬边、台阶与阴影承载，避免正文难以辨认。

首页为海岛营地；路线为航海桌；筛选为收藏陈列室；设置为机械工坊；诊断为信号观测塔；帮助为旅人图书馆。六个模块均可访问，每个场景由本地代码绘制，无素材下载。

功能语境参照现有 Views：开始/停止探索、游戏窗口选择、路线合集整理、点位筛选、地图显示设置、诊断与使用帮助。路线实际选点和开始指引仍在游戏内，本原型不将其冒充为桌面现有功能。路线名、数量、距离、时间、点位等为示例，不是真实数据或实现承诺。

## 可体验内容

- 六页导航与地址 hash；首页卡片跳转。
- 开始/暂停演示探索（也支持 F9）、模拟窗口选择、猫咪对话。
- 三条示例路线选择与手记弹窗。
- 点位分类、搜索、多选与清空；切换页面后保留本次会话状态。
- 地图显示/手柄演示开关，标记大小滑杆及预览。
- 日间/夜幕切换、模拟诊断日志、可展开使用帮助。
- 窄屏布局、键盘焦点、原生弹窗 Esc 关闭、状态播报。

所有状态仅在页面内存中，不读取游戏、不连接核心、不修改真实配置、不存储账号或位置。页面刷新恢复初始演示状态。没有修改托管代码、XAML、发布清单或玩家安装目录。

## 预览

直接打开 HTML 即可。也可在仓库根执行 `python -m http.server 8765 --bind 127.0.0.1 --directory design/pixel-camp`，访问 `http://127.0.0.1:8765`，按 Ctrl+C 结束服务器。
