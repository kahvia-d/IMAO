# 2026.10.3.1

- 新增：设置里的「更新下载源」改为「**下载源管理**」，程序更新可以从 **GitHub** 或 **Mirror酱** 里选一个。
  选定之后，**检查更新和下载更新都只走这一个来源**；切换来源后需要重新检查一次。
- 说明：Mirror酱 的上传晚于官方发布，有时会落后一两个版本。选择 Mirror酱 时，**它还没有同步的版本不会被提示**；
  界面会写明 Mirror酱 与官方各自的版本，并提供「改用 GitHub 并重新检查」。
- 说明：Mirror酱 下载需要 CDK。没有填写 CDK 也可以选择 Mirror酱（检查更新照常），但下载按钮会停用并说明原因；
  已经保存过 CDK 的安装默认继续使用 Mirror酱，不需要重新设置。
- 说明：**地图资源（地区包）不受这个设置影响**。地区包只在 GitHub 上发布，删掉某个地区之后重新下载仍然从 GitHub 取；
  走 Mirror酱 更新程序时，随程序发布的地区包内容会一并更新。
