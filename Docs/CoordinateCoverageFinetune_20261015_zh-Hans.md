# 草地、雪地覆盖与正 X 回放微调对照（2026-10-15）

## 结论

已完成背景覆盖审计、重新划分、两组真实 GPU 微调及原生 CPU 回放。雪地混合场景已进入新训练池；新增六张已有完整标签的正 X 历史图片做有限回放。补齐这些覆盖并未解决旧草地的误加负号，也未让旧雪地通过双路互证，不升级为默认候选。

新 180 帧开发集上，加入正 X 回放组的单路线为 171 正确、1 次错误返回、8 次未返回；未训练同字典对照为 173、4、3。错误返回减少，但漏读增加。与仅调整背景覆盖组相比，正 X 回放增加两帧正确，双路互证却少三帧正确，不能宣称全面改善。

## 素材实际如何使用

逐帧标签审计确认，采集会话中全部 1011 张完整 XYZ 标签的 X 都是负数。原 v1 训练使用前段 828 张，后段雪地没有进入训练。没有发现“训练器漏载雪地”的证据，问题是当时的时间切分没有覆盖全部背景。

## 正 X 补充及训练配方

历史回归资料中找到六张既有完整 XYZ 的正 X 图片：`laguna`、`qiqiu`、`lowervault`、`blackshores`、`timeriftruins`、`black-shores-gameplay`。使用原标签、原图像素和人工检查的坐标裁框，没有翻转符号、合成数字或修改原基准。它们全部从本轮历史评估中排除。

两组都从同一份 v1 数字头预训练初始化开始，不接着 v1 已训练权重续训。保留 14 字符字典及其对应的 16 类 CTC 输出，冻结 151 层 BN 的统计、继续训练仿射参数；Adam/Cosine、学习率 1e-5、固定 5 轮、seed=20261015、batch=16、无增强，训练输入仍为原始背景的 BGR 坐标裁片、3×48×384。

每组主导背景固定安排 320 个采样条目，确保训练池中 731 张均进入采样清单；较小背景组会重复采样，不能把重复当新增图片。另设 128 个等量回放槽：

- `coverage-only`：回放已有采集训练图，合计 731 张唯一图、1728 个采样条目。
- `coverage-positive`：回放六张历史正 X 图，合计 737 张唯一图、1728 个采样条目。正 X 槽占 7.4%，不是 128 张独立正 X 图。

官方 Windows 循环略过最后一个 batch，两组各实际 535 次优化更新、8560 次图像呈现。使用最后一轮 `latest`，没有按开发成绩挑 checkpoint。官方评估只计算 176/180 张，其日志成绩未作为本文结果。每轮具体跳过的图片没有逐 ID 跟踪，因此只声明完整采样清单覆盖，不声称每轮使用了全部图片。

两个训练权重均有 968 个有限参数条目，302 个 BN 均值/方差缓冲区逐字节保持初始化值；其他变化条目分别为 662 和 663。GPU 环境仍有 cuDNN 编译 9.9、可用 9.5 的既知警告，未消除该警告。导出与最终回放使用 Paddle CPU 3.0 和现有原生 CPU 库。

排除六张训练历史图后，剩余历史集为五张完整 XYZ、一张草地 XY、一张待定雪地、四张无坐标图。新两组的 readout-line 单路线及互证均完整 XYZ 5/5，草地未正确返回，四张无坐标均未误报。这仍是小型历史回归，不是新的独立验收。
