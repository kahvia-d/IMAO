# 2026.9.19.1

**地图区域可以按区域管理了**

- 地图资源从"一大坨"改成 **13 个独立区域包**：今州、梦州、拉古那、七丘、冰原地表、黑海岸、
  拉海、暗原、下层金库、阿维诺勒姆、织物工坊、特提斯、时隙遗迹。
- 设置页的「地图区域」现在**打开就有**，不用先点「检查更新」：装了什么就显示什么，
  本机没有的会显示成「未安装 · 下载约 X MB」。
- 每个区域一个开关：**停用**只是不再加载它（文件还在，重新打开立刻生效）；
  **删除**会把本机副本从磁盘上删掉腾出空间，之后重新打开会只下载这一个区域。
- 关掉的区域不再参与定位，定位范围相应缩小，资源占用也随之下降。

**其他修复**

- 修好了「停用某个区域后重启，它还是会被加载」的问题。
- 修好了区域开关在检查更新/下载过程中不停闪烁的问题。
- 图标资源拆成独立资源包，以后图标更新不需要重下整个地图数据。

**说明**

- 区域开关与删除都在**完全退出并重新打开软件后**生效（和地图资源更新一致）。
- 点位进度、路线和个人设置不受影响，仍然保存在本机。
