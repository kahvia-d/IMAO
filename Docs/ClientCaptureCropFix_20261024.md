# WGC 客户端裁剪修正（2026-10-24）

用户已批准先修裁剪，保留模型和解码行为。实机录制证明：窗口帧1922×1119、客户端1920×1080，帧屏幕原点(319,112)、客户端屏幕原点(320,150)，正确裁剪(1,38)，旧算法却用总非客户区差值(2,39)。

## 实现计划

1. [x] 新增独立客户端几何解析器：检查Win32查询返回值，使用ClientToScreen与DWM扩展窗口边界之差；验证尺寸、请求客户端尺寸与WGC帧边界。不能将失败查询或越界裁剪静默降级为零。
2. [x] 新增原生回归：录制1080p和2K窗口、2K/4K全屏、负屏幕坐标、非对称边框、查询失败与窗口切换过渡帧；旧公式对照必须失败，新实现通过。
3. [x] App同时给客户端裁剪和局部回读提供同一几何；局部回读配置作为完整快照读写，拒绝配置与当前裁剪不一致的局部帧。诊断保留实际帧、裁剪及拒绝原因。
4. [x] 用同一生产几何解析器处理玩家78帧的元数据，原生OCR重放结果应与已验证正确起点实验完全一致；不换权重、不放宽断言。
5. [x] 原生构建、真WinUI自包含publish、必要回归；按脚本刷新开发测试树并核对differing=0，完全退出后重启。

实现文件：`WindowsCapture/ClientCaptureGeometry.h`（几何与有效性）、`App/App.cpp`（裁剪消费）、`WindowsGraphicsCapture/SimpleCapture.*`（局部回读几何快照）；测试`IMao-Core/tests/ClientCaptureGeometryTests.cpp`。

本次不修模型、解码器或采集写入吞吐。测试树预期改善本次1080p窗口识别；不能宣称所有分辨率/场景都已解决。
