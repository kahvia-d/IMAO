# 自训坐标模型：图像确认补负号与训练补充

日期：2026-10-16。用户批准的顺序是：先补安全的负号恢复，再分析原 17 张拒识并补充训练，最后用新游戏会话独立验收。前两步已完成；第三步已冻结候选并启动暂停状态的采集器，尚无新会话验收结论。仅离线实验，未接入客户端。

## 如何补负号

沿用上一轮固定 HUD 布局校准：X 首位到左边界的位置，以及 Y 首位到 X 末位的距离。位置只能提出“可能漏负号”，不能直接改坐标。

新增 `sign_recovery.py`：原色路线能解出 XY、布局仅提示漏号时，检查同一裁片的对比度路线。必须实际检测到置信度至少 0.5 的短横框、相邻数字一致、无重叠冲突，并通过像素检查，才能插入该实际短横检测框，重新解码和校验。不能补数字或逗号，不能把基础解码失败当成补号问题。多个可疑轴必须全部确认，否则拒绝返回。

像素检查要求短横有上下相反的边缘，并在左右结束。审阅发现早期梯度检查会接受坡面和横向背景分界；补充反例后修复。再次审阅发现左右平均会掩盖单侧延伸，改为分别检查两侧，采用更强的一侧作为外部背景。保留两轮红绿测试日志，没有为了保留分数降低条件。新增 17 项测试，全套 121 项运行，107 通过、14 项外部集成环境未启用而跳过。

真实开发图中仅第 1059 帧通过补号：恢复 Y，返回 `(-1006,-5601)`。第 1071 帧的负号仍不能通过图像确认，继续拒识。未知配置保留基础返回并明确标为未校准，不视为布局验证通过；当前不宣称跨 UI 缩放可用。

## 训练补充与划分

原 17 张拒识主要分为：5 张缺数字、7 张 XY 字符冲突、4 张缺逗号、1 张漏 X 负号。它们仅用于开发分析，没有加入训练。

从原有 train 分区另选 24 张真实来源：草地、岩石、雪地各 8 张，视觉转录坐标、日期和时钟，并检查原生预处理后的框覆盖图。保留原 76 个来源和字符框，得到 91 张文字来源、9 张背景来源。每张生成实际原生 raw／contrast 两路，共 200 张训练图，每路 2949 个字符框。日期也完整标注。标签由助手视觉复核，不能称为用户逐框验收。

从本机官方通用 `yolo11n.pt` 初始化，使用自有标注，未使用网友游戏模型权重或伪标签。固定 100 轮，采用最后一轮权重；训练工具的 val=train 仅说明拟合，不是泛化分数。这轮同时改变来源、输入路线、种子和训练预算，不是单因素或等算力对照。保持 Ultralytics 等框架归属。

原开发集、整组留出的 776–787 帧和待定 1100 帧均未进入训练。没有改写既有真值；1100 按用户要求继续保留旧值、维持待定隔离。
