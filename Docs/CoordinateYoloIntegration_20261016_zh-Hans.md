# 自训 YOLO 与图像定位交接初版

用户已在对话中确认：SURF 正常时 OCR 低频待命，首次失配即加速；OCR 接管后继续图像搜索，图像可靠恢复后切回。本轮直接在已有 OCR 研究工作树实现，不刷新任何客户端树。

## 实现计划

- [x] 添加独立交接策略及测试：正常 1000ms、失配 250ms；读数不能刷新 SURF 健康时间；接管后需两个不同帧的一致视觉定位才交回。
- [x] 使用已有自训 flight ONNX 单权重，实现原生 CPU 推理、raw/contrast 双路、XY 解码、符号几何和补号证据检查，避免 Python 运行时依赖。
- [x] 对照已冻结的 2012 帧单图 CPU 结果，分别核验解码移植与真实原生推理。保留差异，禁止改旧标签或旧基准。
- [x] 接入异步识别入口及 App 调度：后台预热、低频读数、失配立即提交、时效/代际检查、稳定恢复后切回。
- [x] 构建原生程序及真实 WinUI；登记证据与未验收项。玩家安装目录及 out/map-test 均不修改。

## 边界

单权重为本项目自训 flight 模型；权重来源与摘要另附模型说明。模型分数使用检测器语义，不沿用 Paddle 的 0.85 文本分数阈值。保留区域身份、跳变、负号与多帧确认检查。不同分辨率允许按 HUD 比例取景，但只有已有标注的 2560×1440 布局享有符号位置标定；未标定布局不得套用补号规则。

验收同时检查：首次失配至接管延迟、恢复交回、无坐标画面、过期异步结果、重复帧、场景切换、两路冲突、连续移动。离线正确不等于实机已验收。

## 初版行为

游戏 HUD 可见、聚焦且捕获新鲜时后台加载 `Assets/models/coordinate-yolo`；SURF 正常时每秒最多提交一次读数，首个局部匹配失败或缺特征时切换至至少 250ms 的提交间隔。一个在途请求和重复帧限制保持有效，因此这不是固定完成频率或接管延迟承诺。

每次读数必须通过 raw/contrast 同帧互证；通过现有区域、镜像、跳变和轨迹检查后，还需两个不同截图的读数在合理移动范围内连续确认。待命读数也参与确认，但只在视觉位置可疑时发布。无输出会断开读数确认串。结果最多接受截图后 750ms，不能用返回时刻冒充截图时刻，不能覆盖更新的绝对定位。

OCR 接管不改变 SURF 健康时间，局部匹配持续尝试，同时每 500ms 最多调度一次全局搜索（实际受在途搜索限制）。切回要求两个不同截图、同场景、相距不超过 750ms 且位置合理的绝对图像定位。全局候选必须在当前截图重新通过特征匹配；纯轮廓/像素自证不能使 SURF 恢复。两次有效全局复核之间允许夹杂失败的局部搜索，否则稀疏区域无法通过全局恢复。隐藏 HUD、开大地图、失焦等会清除交接状态。

## 验证证据

本地证据目录为研究工作树的 `out/yolo-integration/`：

- `decoder.json`：冻结单图 CPU 检测框经过 C++ 解码，XY 与可选 Z 为 **2012/2012** 一致。
- `inference.json`：实际原生 ONNX Runtime 单图 CPU 推理，XY 与可选 Z 为 **2012/2012** 一致。
- `preprocessing.json`：本轮采集的 **435** 张源裁切，raw/contrast 与此前原生离线预处理逐像素一致。
- `CoordinateHandoffTests`：首次失配、OCR 不修复 SURF 健康、重复帧、时效、场景和恢复确认。
- `CoordinateYoloDecoderTests`：数字冲突、优势互证、缺分隔符、溢出、可选 Z 冲突和无证据不补负号。
- `IMaoCoordinateRuntimeTests`：真实异步模型加载、快照像素所有权、请求元数据、输出与直接推理一致、模型缺失明确失败。
- 原有 `IMaoOptimizationTests` 通过，既有断言未修改；旧 `IMaoCoordinateRegression` 构建通过。
- 真实 `Build-IMao.ps1` WinUI 构建、自包含、六页导航元数据及资源快照检查通过。研究工作树原先的 LFS 指针从已有本地对象还原，没有网络下载大资源。

比较脚本：`tools/coordinate-ocr/verify_native_yolo.py`。这只证明移植一致性，不把已有样本重新称为独立验收。

独立只读审阅指出旧回归目标漏链接两个 YOLO 源文件，已补齐并构建验证。单模型只使用新权重，没有加载旧自训权重作为后备。Paddle 的历史离线兼容入口及依赖暂保留，App 的两处预加载均已切换 YOLO。

## 待实机验收

本轮没有刷新 `out/map-test`，没有更改或启动玩家安装。尚未测量真实游戏中的接管延迟、频繁切换次数、移动位置误差与帧时间成本。下次刷新开发测试树时须先退出客户端，按现有整树同步脚本操作，并核对 `differing=0` 后重启；不能只复制本轮 exe 或模型。
