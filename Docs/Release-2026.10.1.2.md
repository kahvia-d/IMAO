# 2026.10.1.2

- 新增：**路线合集**。保存过的路线现在可以分门别类地放：新建合集、给合集改名、删除合集，也可以把一条或一批路线移到别的合集里。你以前保存的路线**自动归入「默认合集」**，不需要做任何迁移。在游戏内大地图的「路径自动规划 → 路线列表」里切换合集，之后保存的自动路线和手绘路线就都进当前合集——手绘的保存按钮上会写明要存进哪一个合集。
- 新增：**路线的导入与导出**。勾选若干条路线导出成一个路线包，也可以把一整个合集导出。导入时程序自己认出这是路线包还是合集包：路线包进当前合集，合集包会新建合集并切换过去。如果导入的合集和你已有的重名，会问你是「覆盖」（用导入的换掉现有的）还是「新建」（另外建一个，两边都留着），覆盖前会告诉你各有多少条。
- 调整：**桌面端的「路线」页只负责整理**。这一页去掉了那些点了不会生效的按钮（选点、框选、套索、指定起点、手绘、生成预览等——它们都需要游戏里的大地图在场），现在是「路线怎么操作」的讲解加上一份带图标的路线列表。要开始指引一条路线，请在游戏内的大地图工具台里点它。
- 修复：**路线列表里每一行中间会多出一条空白行**（游戏内的路线列表没有这个问题）。
- 调整：路线页右侧按钮的文字改得更直白（「批量操作」「导入路线包」「导出当前合集」），不再以省略号结尾——那个省略号看起来像程序把文字截断了。
