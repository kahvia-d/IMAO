## 证据与复核方式

有总览图的部分使用 SIFT 地图配准生成候选，距离仅用于缩小范围。再将跟跑关键帧与库街区攻略描述、攻略图片交叉核对，比较触发物、地形、建筑、起点和奖励终点。没有总览的部分根据视频路线、收集计数和场景筛选候选。所有已确认记录均保留视频帧、实际核对的攻略图片和攻略 JSON。

全视频采用 480p 媒体与 5–15 秒接触表浏览，歧义处补充更密集帧及原图。未进行连续逐帧观看、音频转写或当前游戏版本的探测仪实测。

二次复核纠正了同类挑战混淆：瑝珑 P8 花圈应在 326–336 秒；P9 的河豚、废墟竞速与浮城竞速分别对应不同路段；P10 原以空圆台确认的挑战已撤回，三石柱隙声蝶段则在核对独有地标后确认。原始初轮笔记保留供追溯，构建脚本强制应用补充复核，不能直接用初轮笔记生成标签。

## 尚未解决的边界

- P9 的 624–678 秒断轨列车竞速已单列未知目标；不能复用浮城朴素箱的身份。
- P10 的 1092–1104 秒三株碧蝶花出现基准箱：视频事件明确，但尚未核清对应总览标记和库街区身份。单独记录在 `coverageConcerns`，暂不增加目标计数，避免重复。
- 乘霄山南北两组三档滑雪奖励均已核对。pin7 剑形挑战与 pin15 精密箱身份仍未知。后续复核将片尾 639–642 秒辉光箱与 pin13（页面标记14）攻略第2图对应：水岸、右侧平石、木障碍及前景圆形石纹一致，ID 为 `1253810339575873536`。原补充审计中片尾金箱的覆盖疑点已解除，修正记录在 `resolvedCoverageObservations`；它本已计入正例，不增加数量，也不解决标记16精密箱的跟跑对应。三箱组成员编号不代表视频开箱次序。
- 部分视频缺少独有地标、存在多档奖励或同机制邻近点；部分候选攻略接口或图片下载失败。逐条原因保留在来源结果文件。
- 沿途路过的普通箱单列观察，不因出现在攻略里就自动赋予遗漏属性。抽帧可能遗漏跳剪或短暂事件，不能宣称全覆盖到每个独立奖励。

## 复现与验证

在仓库根运行（Python 需 requests、OpenCV、Pillow、numpy；地图输入及证据目录必须已存在）：

```powershell
. .\scripts\Enter-DevEnvironment.ps1
python -X utf8 tools/MarkerDetectabilitySpike/build_root_results.py
python -X utf8 tools/MarkerDetectabilitySpike/build_collection_review.py
python -X utf8 tools/MarkerDetectabilitySpike/validate_collection.py
git diff --check
```

汇总与校验脚本不下载、不修改运行时地图。本轮校验通过：383 条记录、1,461 张不同证据图片、1,795 条不同证据路径及 26 个视频摘要。校验包含点位 ID/state/type、攻略 JSON 身份、证据图片可读性、时间范围、26 个分 P 的记录覆盖、视频 SHA-256，以及未知项不会进入正例清单。图文页面另行检查搜索、状态筛选及证据图片加载。完整性校验不能代替视觉正确率或游戏实测。
