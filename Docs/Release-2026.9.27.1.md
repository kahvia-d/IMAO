# 2026.9.27.1

- 大地图的识别方式变稳了。以前是数左上角那块金色图案里有多少像素来判断"是不是在大地图"，而小地图和侧边面板上也有相似的图案，会互相干扰；现在改为直接比对控件本身的形状。
- 修复大地图开着时，地图标记会忽然消失、手柄提示「请等待大地图或大世界画面」的问题。原因是刚打开地图的一两秒里，画面校验还拿不到需要的内容，程序把它当成了「确认不是大地图」；现在这种情况会保留上一次的判断，不再误清。
- 手柄模式下在地图上打开「手柄助手」这类面板、挡住左上角图案时，不再影响大地图的识别。
- 在 16:10、4:3 等非 16:9 窗口下同样验证了识别位置（1600x1200、1920x1200 实机确认）。
