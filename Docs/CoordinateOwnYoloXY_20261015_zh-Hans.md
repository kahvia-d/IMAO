# IMao 自训 YOLO：XY 必需，Z 可选

用户明确当前只要求正确的 XY，Z 可选。本轮按此重新计分，并实现局部字符冲突隔离：**同一自训权重、同一检测框，XY 从 137 正确／1 错误／32 未返回，改善到 153 正确／1 错误／16 未返回**。141 张无坐标图仍零误报，草地整组留出从 11/12 到 12/12；雪地 32/40 暂无改善。

这是离线解码与评测改动，没有重新训练、下载、修改生产 OCR 或替换客户端模型。权重仍为[上一轮扩充训练](CoordinateOwnYoloExpansion_20261015_zh-Hans.md)的自训 YOLO11n。网友权重和输出不进入本轮解码；仅在单独的只读脚本中，对既有网友结果重新按 XY 计分作比较。

## 计分口径先纠正

旧报告 133/170 要求 XYZ 全部正确。5 个错误中有 4 个仅 Z 错误，因此**完全不改解码器**，仅按当前 XY 要求重计，即为 137 正确、1 错误、32 未返回。不能把这 4 张算成模型改善。

旧 XYZ 报告、断言、坐标标签均保留不变；新文档与新证据单独记录用户的新需求。第 1100 帧继续待定，没有因其新返回而改标签。

## 新解码规则

实现位于 `tools/coordinate-ocr/xy_decode.py`，只读字符、分数、位置框。仍使用检测分数 0.25 与冲突 IoU 0.45，不使用真值、小地图、前一帧坐标或固定负 X 先验。

1. 先按预测框的水平间距分组，同类同框去重，不在整幅图上提前因类别冲突拒绝。
2. 必须观察到 `X,Y,`：要求两个整数和两枚逗号，第二枚逗号是 **Y 字段的结束证据**。Z 可以完全缺失；不能仅因出现 `X,Y` 的残片就认为 Y 完整。
3. XY 必需前缀存在冲突、明显字符间断、邻近的独立正负号或数字残片时拒绝，不把残片直接拼回。多组可能坐标不改选其中一组；冲突破坏语法也不能绕过检查。
4. 日期等其它组的冲突不否决 XY。第二枚逗号后的 Z 冲突只使 Z=null，包括 Z 的备选字符被检测成逗号；独立多出的逗号仍视作边界歧义并拒绝。
5. Z 只有在自身语法、范围、连续性和冲突检查通过时才附带返回。XY 分数与 Z 分数分开，Z 不参与 XY 最低分数。

这些检查只能利用已经观察到的框。模型完全漏掉一个负号或数字、又没有留下可见残片时，解析器不可能保证发现；不会通过猜符号掩盖这种错误。Z 也不是人工确认值。
