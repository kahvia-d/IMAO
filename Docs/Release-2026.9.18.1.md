# 2026.9.18.1

> **本版"DirectComposition 帧率更高"的说法已撤回。** 本版把 DirectComposition 设为默认，
> 是根据一次**不足以支撑该结论**的对比做的决定：那次测到的窗口和随后发布的窗口样式不同，
> 而且两组条件是前后相接、没有交替对照。**2026.9.18.2 已把默认改回「分层窗口」**，
> 升级后会自动切回去，不需要手动设置。

这一版解决"用工具时游戏掉到 100 帧、而且不丝滑"的问题。

**掉帧**

以下说法已撤回（数字本身没错，是结论不成立）：

- ~~之前的叠加层用一种较老的画面合成方式，会让 Windows 多绕一道，游戏因此稳定损失十几帧。现在改用 DirectComposition 呈现。~~
- ~~同一台机器、同一个场景实测：帧率 101 → 115（工具关闭时约 120）；明显卡顿的帧（慢于 20 毫秒）从 17.5% 降到 1.8%。~~

**如果画面显示异常**

DirectComposition 需要较新的 Windows 和显卡驱动。如果叠加层显示不正常，在 设置 → 叠加层呈现方式 里改回「分层窗口」即可，两种方式都不会影响定位和标记功能。

**其它**

这一版同时修复了使用 DirectComposition 时鼠标点击无效的问题。
