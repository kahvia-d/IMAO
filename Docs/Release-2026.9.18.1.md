# 2026.9.18.1

> **本版"DirectComposition 帧率更高"的说法不准确，已撤回。**
> 默认已在 2026.9.18.2 改回「分层窗口」，升级后会自动切回去，不需要手动设置。

这一版解决"用工具时游戏掉到 100 帧、而且不丝滑"的问题。

**掉帧**

本版关于"改用 DirectComposition 后帧率 101 → 115、卡顿帧从 17.5% 降到 1.8%"的说法不准确，已撤回。

**如果画面显示异常**

DirectComposition 需要较新的 Windows 和显卡驱动。如果叠加层显示不正常，在 设置 → 叠加层呈现方式 里改回「分层窗口」即可，两种方式都不会影响定位和标记功能。

**其它**

这一版同时修复了使用 DirectComposition 时鼠标点击无效的问题。
