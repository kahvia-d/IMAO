# 2026.9.19.2

**修好了"区域包删了拿不回来"这一类问题**

- 删掉某个区域的本地副本后，重新启用会**真的重新下载**它（之前会显示"已启用/未安装"却什么都不做）。
- 下载完成后**立刻显示为已安装**，重启之后也仍然是已安装（之前重启会退回"未安装"）。
- 未安装的区域，行尾直接是**「下载」**按钮：点它就下载并启用，不必再去拨开关。还没检查过更新时
  它是灰的，点一下「检查更新」就能点。
- 把区域**停用到只剩一个**（甚至只留一个完全不同的区域）也能正常启动核心；之前会让核心启动失败，
  界面卡在"正在启动 CoreHost"，窗口也关不掉。现在核心若真的起不来，会**立刻**给出原因而不是一直等。

**不再随程序分发基础地图特征库**

- 每个区域包都自带已校准的特征，程序包不再包含那套 150 MB 的基础特征库，**下载体积相应减小**。
- 区域包、图标包的更新继续走地图资源渠道，可以按需下载或删除。

**说明**

- 区域的停用 / 删除 / 重新下载都在**完全退出并重新打开软件后**生效。
- 点位进度、路线和个人设置不受影响，仍然保存在本机。
