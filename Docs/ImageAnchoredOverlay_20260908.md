# 地形图像跟随与小地图浮动修复（2026-09-08）

> 同日后续：针对实机反馈的闪烁与快拖错位，已继续修复 HUD 漏检、旧坐标绑定新图片及异步确认时序。最新行为与验证见 [小地图闪烁与大地图快拖错位](OverlayContinuityFix_20260908.md)，其中捕获期限与大幅预测分歧处理取代本文对应描述。

## 问题与证据

用户反馈：上一版消除了明显跳动，但小地图在走动、转视角时仍有小范围浮动，大地图拖动和缩放存在过渡动画般的滞后。

检查 `events-20260907.jsonl` 的 23:30–23:46 会话后，发现绘制通常已有 42–58 FPS，但定位快照约 10–11 FPS，画面来源的年龄可超过 100 ms。绘制和定位频率的差距此前由时间插值、速度外推填充；这些估计无法知道玩家何时停止或反向，也会把定位噪声变成缓慢移动。

小地图还有两处独立的几何问题：

- 局部匹配每帧重新拟合旋转和比例。转视角时方向图形改变了可用地形特征的分布，即使仍有足够内点，小幅旋转、比例误差也会偏移推算的中心。
- 标记使用旧的屏幕宽度公式，定位使用实际裁剪后缩放到 184 像素的图像，两者比例不同。2560 宽窗口下，旧投影为 1.35 屏幕像素/地图单位，246 像素裁剪按名义比例应为 `246 / 194 ≈ 1.268`，相差约 6.5%；裁剪中点与原硬编码中心也不完全一致。

这些日志可以支持更新频率和定位波动的判断，但该时段没有新的诊断图像，不能据此测出真实游戏中的逐帧附着误差。

## 实现

### 直接跟踪地形，不再补时间动画

移除原来的速度外推和指数平滑。`ScreenMotionTracker` 从当前截图测量地形的平移、缩放，标记使用测得的变换直接绘制；重复同一截图或单纯等待不能改变位置。

跟踪使用分布在地形上的图像块、梯度亚像素对齐和空间一致性检查，必要时回退到图像金字塔和 ORB。小地图只允许平移，并屏蔽中心人物、边框及明亮彩色图标；大地图只允许平移和统一缩放。至少需要 12 个内点、65% 支持、一像素残差检查及足够空间覆盖，未放宽全局定位的接受条件。

`ImageAnchoredOverlay` 处理定位快照与截图不同时刻的问题：保留主图像参考，分别计算参考到定位帧、参考到当前帧的变换，再转换标记坐标。每次定位结果到来不会强制重建参考，避免把短基线注册误差不断积分。只有足够的实际位移/缩放才更换地形参考；场景、界面代际、尺寸或可靠性改变时重置。

小幅绝对定位变化受到当前地形图像约束，修正范围限于小地图 6 像素、大地图 12 像素及约 2% 比例。超过范围会重新采用绝对定位，不让旧图像参考掩盖真正的场景变化。截图超过 100 ms 或无法可靠跟踪时不继续绘制旧标记。

标记、路线及输入逆变换使用同一个实际显示变换。此前的界面可见性撤销机制继续生效。

### 分离采集和定位

新增独立采集线程，目标间隔 16.667 ms，定位仍遵守原更新配置。定位器和绘制器读取最新的不可变截图快照，不排队处理过期截图。

现有 PrintWindow 路径复用顶向下 DIB 和内存 DC，尺寸或线程改变时重建，去掉每帧资源分配及 GetDIBits 读回。每次发布的 BGR 图像仍有独立内存；尺寸在采集过程中改变时丢弃不一致的帧。截图方式及用户设置未改变。

`capture-cadence` 记录实际采集 FPS；`overlay-motion` 增加 `mode=image-anchored`、`captureFps`、`captureAgeMs`、`attachedFps`、`trackingMisses`，并保留绘制/定位频率，供下次游戏内测量。

### 统一小地图几何

首次可靠视觉识别确定地形比例，在正常局部跟踪时保持该比例和正北朝向，只拟合平移。全局搜索、跨区域恢复仍保留原有几何验证。

标记和路线统一使用实际整数裁剪中点与 `裁剪宽度 / 184 / 地形比例` 投影。回放工具也使用首次确认的比例，逐帧检查局部跟踪没有悄悄改回名义比例。

## 验证

主要证据位于 `out/image-anchored-overlay-20260908/`。

- Release 核心构建成功，原生优化测试及 106 项托管运行时检查通过；托管检查包括真实 CoreHost 管道启动、配置、重启和退出。
- 最终资源自检通过：`resourcesReady`、`visualReady`、`viewportReady` 都为 `true`，`error` 为空。
- 真实截图叠加已知平移/缩放的回放覆盖停止、反向、25 像素突变加 8% 缩放，旋转方向锥覆盖的小地图回放也通过。单帧跟踪约 1–2 ms 是离线图像测试耗时，不是游戏采集耗时。
- 集成回放加入 80 ms 定位更新、32 ms 延迟和持续约 ±1.3 像素定位误差，平移达到 24.7 像素并跨过内部重锚阈值，检查地形附着、历史帧回看、停止、反向及点击逆变换。大地图最大误差约 0.010 像素，小地图约 0.068 像素；相同截图等待 60 ms 后位置严格不变。
- 每种模式模拟 192 秒、12001 张截图、20 次低速往返及 2401 次定位快照。大地图全程最大误差约 0.012 像素，小地图约 0.028 像素，回到原位残差都低于 0.001 像素，没有在该序列中出现累计漂移。
- 受控特征对应测试中，固定比例和平移拟合的中心 RMS 误差从 0.468 降至 0.193 地图单位。1280、1600、1920、2560、3840 宽度下的投影都与实际裁剪一致。
- DIB 隔离测试使用实际采集实现、真实 OpenCV 和替代 GDI 调用，10 项检查通过，覆盖 80 帧缓冲复用、已发布图像不可变、线程交接、尺寸变化、并发串行化、失败回退及资源释放。证据：`out/capture-dib-20260908/validation.log`。
- 既有 29 张截图回归通过，要求发布的 2/2 样本通过，标注样本误发布为 0。跨区域真实截图序列两帧独立确认后，8 帧局部跟踪全部成功，始终保持首次校准比例 `1.0693268953624524`；两个负例拒绝。恢复提示的 3 帧及大地图的 8 个样本也全部通过。报告位于 `visual/`；跨区域坐标只验证与既有参考一致，没有独立的实测真值。

复现命令：`scripts/Test-Runtime.ps1 -OutputDirectory out/image-anchored-overlay-20260908 -Parallel 4`。视觉回放使用现有 `IMaoVisualRegression.exe`，依次执行 `20260906-regression.json`、`20260907-cross-area.json`、`20260907-resume-hints.json` 和 `20260906-viewport.json` 清单。

以上运动误差来自已知变换的离线回放，不是实时游戏体验测量。PrintWindow 本身仍是同步采集，实际延迟与采集频率需要通过新版日志和游戏内操作确认；不能据此保证 60 FPS 或零延迟。
