# 2026.9.26.2

- 不再要求 16:9 游戏画面：16:10（2560×1600、1920×1200 已实测）与其它客户区形状都能开始探索，此前非 16:9 的画面会在点「开始探索」时被直接拒绝。
- HUD 区域改用游戏自身的缩放与贴边规则定位。修复非 16:9 画面下小地图被纵向压扁、任务图标定位框下移 36 像素导致状态判成「没有 HUD」、以及坐标读数在部分分辨率下无法识别的问题。
- 修复大地图在非 16:9 画面下打开约两秒后回到「等待游戏画面」的问题：大地图右侧的缩放条此前按贴着画面下边缘定位，实际是相对画面竖直居中，定位框因此偏低 60 至 150 像素，缩放控件始终识别不出，大地图状态随之失效。
- 新增本地记录本：可以保存多份探索记录，每份可绑定一个库街区账号，同步只写入当前使用的那一本；记录本重写之前的旧进度可以带入任意一本，同步未上传成功的完成状态也会保留。
- 设置中的记录本改为一览表：首列单选用哪一本，操作只保留新增、改名与删除。
- 分层地图的楼层判定改为依据该层自己绘制的美术，而不是脚下的地面：站在地表却被判成某个洞窟层的假阳性不再出现，点位只在玩家实际所在楼层显示。
- 修正隐海试验场的楼层坐标原点：该区域此前定位整体偏移约十一个地块，点位与位置都不正确。
- 本次同时更新地图资源包，程序更新后按提示下载受影响的区域即可。
