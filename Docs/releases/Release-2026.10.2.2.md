# 2026.10.2.2

- 改进：**程序更新会记录每一次尝试**，而不只是成功的那一次。此前更新日志只记录失败原因和"准备完成"，于是当界面上先显示「Mirror酱 已备好增量包」、随后却从 GitHub 下载完整程序包时，日志里什么也看不到，无法判断是镜像给了整包、镜像的文件被拒、还是中途换了来源。现在会记录两行：拿到更新来源答复时（偏好来源、Mirror酱 给的是增量还是整包、大小、版本），以及一次尝试以取消或失败告终时（是否取消过整包确认、清单下载次数、Mirror酱 的拒绝原因）。这两行只在排查更新问题时才会被看到，不影响日常使用。
- 说明：本版同时改为**分片发布**。此前的版本以整包形式发布，更新时必须下载约 1 GB；本版起改按分片发布，更新只下载内容有变化的分片（界面改动通常约 130 MB，仅资源改动时更小）。首次安装仍然使用完整包，发行页里保留一份。

> 已知问题：当 Mirror酱 只提供完整程序包时，界面会先询问是否接受约 1 GB 的下载。这个问题尚未修复，本版仅加了记录以便定位；选定来源前先等 Mirror酱 备好增量包会在后续版本中处理。
