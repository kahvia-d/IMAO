# 2026.9.28.2

- 修复：部分机器上大地图与小地图的标记会**一闪一闪**。此前只要某一帧的界面识别偶发漏掉一次（罗盘或缩放控件被挡住、小地图贴图瞬间对不上），整层标记就会被当场撤掉，下一帧再画回来；在识别会连续几帧漏判的机器上，标记因此一直通断。现在标记层会容忍短暂漏判再接续判定，并且只在画面确实换成了另一层界面时才撤掉。
- 修复：大地图打开期间的一次偶发识别丢失，不再把整块浮层从小地图面板切回整屏、又从整屏切回小地图面板；大地图浮层的尺寸改由「地图是否开着」这个已经带迟滞的判定决定。
- 修复：大地图打开期间的一次偶发识别丢失，不再重置大地图定位会话（此前每次都会丢弃已经算好的视口并重新匹配一次，标记要等约三分之一秒才能回来）。
