# 2026.10.6.1

- 优化：手绘路线改为单击添加点位、按住左键从一个点拖到另一个点建立有向连线。重新拖拽可修改连接与方向，路线编号随顺序实时更新；未连接点随路线保存，后续编辑可继续连接。
- 新增：游戏内路线列表顶部增加「修改路线」，选中已保存的手绘路线后即可继续添加点位和调整方向；修改保留路线名称、所属合集及已有完成状态，兼容旧手绘路线和路线包导入导出。
- 新增：手绘编辑时，悬停点位并在提示后再次按下退格键可移除该点；删除中间点后自动连接前后点，Ctrl+Z 可撤销加点、改线和删点。普通点位仅移出路线，不删除原始点位或全局完成记录。
- 新增：桌面路线列表支持合集内拖拽排序，拖动时显示源路线及插入位置，松开后通过动画移动路线并补位。修复拖动排序闪退、落位刷新闪烁及底部插入标记被裁切的问题。
- 新增：游戏内路线列表可开启「自动轮换」，当前路线收集完成后按合集顺序导航下一条路线，跳过已完成路线，到合集末尾停止；暂停、跳过或退出导航不会触发轮换。
- 修复：采集刷怪模式的范围自动完成仅作用于当前导航目标，避免相邻但不连续的路线目标同时完成；隐藏点位不再因坐标重合被误加入手绘路线。
- 优化：自由点标记不再合并显示。大小地图上的普通点位默认在图标重叠超过一半时合并，「设置 → 操作优化」可调整合并阈值，范围为 1–100。
- 修复：批量导出默认文件名使用路线名，单条为「路线名.json」，多条为「首条路线名（N条路线）.json」，仍保存为一个路线包，并处理文件名中的非法字符。
