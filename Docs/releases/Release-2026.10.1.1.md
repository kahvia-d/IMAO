# 2026.10.1.1

- 修复：**走出分层地图（洞穴、舱段等）之后，地表上的标记有时不再恢复**。在分层地图里只显示当前楼层的标记是设计如此，但此前离开之后，程序仍可能认为玩家还在里面，于是把地表上的点位一直隐藏着——表现为小地图上只剩两三个标记，而大地图上点位是齐的。现在画面一旦不再属于该楼层，数秒内就会恢复地表的显示。
- 修复：**程序更新可能失败并回退到旧版本**，提示「当前程序文件损坏」或「程序目录包含清单之外的文件」，而且此后每次更新都会失败。这类提示来自程序运行时自己写在程序目录里的文件（不是任何一次发布的内容），更新程序此前把它当成了损坏迹象。现在这类文件不再被当作损坏，程序也不再往那个目录里写它。
- 修复：**天槎空间站一带走出舱段后标记不恢复**更常见，因为空间站的地图正好画在地表同一片区域的下方，两种情况共用同一坐标。上述第一条修复同时覆盖了这里。
