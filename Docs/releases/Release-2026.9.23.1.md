# 2026.9.23.1

## 分层地图

- 洞穴、地下建筑等**分层地图**现在会被自动识别：进入后地图只显示玩家所在那一层的点位，
  同一分层地图其他楼层的点位以暗淡图标加「上／下」角标区分，地表点位自动隐藏。
- 走出分层区域后地表点位立即恢复显示。站在洞口、建筑门口这类两层交界处时，两层点位同时显示，
  不因边界判定而隐藏任何一边；站在分层地图覆盖到的那块地表面上时同样如此。
- 分层地图内的点位在「附近」与攻略候选里会带上所在楼层名，避免同名点位分不清；快捷键只会选中
  玩家所在楼层或同层的点位。
- 覆盖范围：今州、梦州、拉古那、七丘、黑海岸、拉海洛、下层金库、黯原、隐海试验场、泰缇斯之底，
  共 57 个分层地图、90 个楼层。

## 其它

- 攻略大图窗口在关闭攻略后一并回收，不再留下隐藏窗口。

## 说明

- 分层识别依据小地图画面本身。少数楼层画面高度相似时，程序会把它们一并当作当前位置显示，
  而不是猜一个再把它标成楼上或楼下。
- 点位完成记录、路线、筛选与个人设置不受影响，仍保存在本机。
- 本次包含新的地区瓦片包（分层地图底图与楼层索引），更新下载量大于仅程序更新；
  之后的版本只下载有变化的分片。
