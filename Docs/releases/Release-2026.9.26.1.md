# 2026.9.26.1

- 检查更新新增 Gitee 镜像作为回退来源：GitHub 无法访问时改用镜像读取同一份签名清单。两份清单都要通过同一个内置公钥校验，镜像只提供可达性，不改变可信来源。
- 设置 →「版本与地图资源」新增「更新下载源」卡片，可填写 Mirror酱 CDK。填写后程序更新先从国内 CDN 下载，失败自动回退 GitHub 分片；不填写不影响检查更新，也不影响从 GitHub 下载。
- 更新来源现在可见：检查更新后在上次检查时间旁注明「更新清单来自 GitHub」或「更新清单来自 Gitee 镜像」；程序包准备完成后注明来自 Mirror酱还是 GitHub 分片。名称取自实际使用的来源，不取自配置。
- 「更新下载源」卡片右侧显示 GitHub 与 Mirror酱 的连通性，可手动刷新。探测只发送请求头，不下载任何内容，也不会占用更新按钮。
- 程序更新若只能取得完整程序包（约 1 GB）而不存在增量包，下载前先请求确认；取消后不影响当前程序与地图资源。
- Mirror酱 CDK 以当前 Windows 用户的 DPAPI 加密保存在本机，不写入日志、导出或崩溃报告；界面只显示其后四位。
