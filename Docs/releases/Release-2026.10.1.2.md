# 2026.10.1.2

- 新增：**路线合集**。保存过的路线可以分门别类地存放：新建合集、给合集改名、删除合集，也可以把一条或一批路线移到别的合集。此前保存的路线自动归入「默认合集」，不需要做任何迁移。在游戏内大地图的「路径自动规划 → 路线列表」里切换合集之后，保存的自动路线和手绘路线都会进入当前合集，手绘的保存按钮上会写明要存进哪个合集。
- 新增：**路线的导入与导出**。可以勾选若干条路线导出成一个路线包，也可以把整个合集导出。导入时程序自动识别路线包与合集包：路线包导入当前合集，合集包会新建合集并切换过去。导入的合集与已有合集重名时，会询问是「覆盖」（用导入的替换现有的）还是「新建」（另建一个，两边都保留），覆盖前会说明两边各有多少条路线。
- 调整：**桌面端的「路线」页只负责整理**。该页移除了在桌面上不会生效的按钮（选点、框选、套索、指定起点、手绘、生成预览等，这些都需要游戏内的大地图在场），现在由「路线怎么操作」的讲解和一份带图标的路线列表组成。要开始指引某条路线，需要在游戏内的大地图工具台里点选它。
- 修复：**路线列表的每一行中间会多出一条空白行**（游戏内的路线列表没有这个问题）。
- 调整：路线页右侧按钮的文字改为直接说明动作（「批量操作」「导入路线包」「导出当前合集」），不再以省略号结尾——该省略号看起来像程序截断了文字。
