# 2026.9.28.4

- 新增「路线列表」：游戏内大地图的「路径自动规划」窗口里多了「路线列表」按钮，点开是一个大一点的窗口，把保存过的路线一条条列出来，每条都写着名字、**有多少个点**、属于哪张地图、是自动规划还是手绘，以及**这条路线用到哪些点位类型**（显示成类型图标 + 名字）。点某一条就直接切换过去开始指引，不用再从桌面端加载。
- 列表最上方是「当前路线」，可以直接保存、删除；还没保存的预览也能在这里存下来。
- 选一条路线开始指引时，**地图会临时只显示这条路线用到的点位类型**，这样路线上每个点位的图标都看得见，不会被你原来的筛选挡住。**退出导航时自动恢复你自己原来的筛选**——期间不会真的改掉你的筛选设置，就算导航中途关掉程序也一样。
- 新增**手绘路线**：在路线列表里点「开始手绘」，回到大地图后**点击要标记的位置**就会记一个点（也可以按一次手绘快捷键 Q 记下鼠标当前位置）。第一个点是起点、最后一个是终点，中间按点击顺序连线。点在**已有点位上就连接到那个点位**（会和路线规划选点一样高亮，重叠的点位会弹出成员列表让你挑），点在**空地上就生成一个带编号的小圈**（这种点没有图标，只存在于这条路线里）。
- 手绘出来的路线**和自动规划的路线存在一起**、显示在一起：同一套列表、同一套切换、同一套保存删除，颜色和线型也一样（实线 + 中间的箭头表示行进方向）。
- 按 **Esc 结束手绘但不会丢掉画好的内容**：画到一半的线、起点终点标记、编号小圈、已有点位的高亮都会留在图上。回到路线列表可以**继续绘制**、**保存**或**放弃**；按 **Ctrl+Z** 撤销上一个点。
- 你以前用旧版本手绘的路线**会自动导入**成手绘路线（原文件一个字节都不动，另存一份归档在 `SavedRoutes/Legacy/`），可以在列表里直接看到并使用。
- 工具窗现在**记得你上次停留的页面**：收起后再打开还是刚才那一页（路线规划 / 路线列表 / 点位筛选），不用每次从最外层点起。
- 修复：路线列表里的点位类型图标此前显示不出来（显示成 `SP_Icon…` 这样的内部编号）。
- 修复：路线工具栏的按钮此前有几处与实际行为不符的说明文字（例如手绘必须按快捷键），现在按实际行为重写。
