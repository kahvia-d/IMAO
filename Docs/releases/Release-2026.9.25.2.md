# 2026.9.25.2

- 小地图范围内没有未完成点位时，攻略键改为打开当前正在导航的路线目标攻略；路线暂停或结束后不再弹出无关点位。
- 攻略窗口新增「跳过」：只有正在导航的当前目标才提供。键鼠按住 G 0.6 秒或单击按钮，手柄长按 Y 0.6 秒。跳过只推进路线进度，不修改点位完成记录，可在路线页撤销。
- 攻略窗口改用 Enter 放大图片、Enter 或 Esc 退出大图；手柄呼出的攻略不再抢占前台，左摇杆按下在攻略窗口与游戏之间切换聚焦。
- 修复手柄模式下长按完成或跳过后，游戏会额外执行一次按键动作的问题。
- 修复攻略收起后焦点未回到游戏，导致手柄无法切换聚焦或退出攻略的问题。
- 修复路线工具栏左摇杆在换行处的方向选择。
- 修复新增跳过快捷键与旧版自定义绑定冲突时，运行设置被整体重置的问题。
