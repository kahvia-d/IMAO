# 地图标记退出、过滤器及诊断布局修复

## 地图界面消失后的标记

日志中 21:48:25、21:49:08、21:49:22 出现大地图控件已经消失、观察结果为 Unknown，但稳定状态仍为 BigMap 的情况。原状态机等待约 10 次采样后才退出旧状态；绘制线程同时继续消费已发布的旧标记帧，清空后台缓存不能立即撤销这些标记。

新增独立的界面可见性快照，绘制和点位交互每帧检查它。下一次捕获确认地图/HUD 消失便隐藏标记，不再等待定位状态机的防抖；可信位置及恢复线索继续保留。界面重新出现后要求来自新捕获的标记帧，避免旧结果闪回。失焦、空图、捕获异常和停帧过期同样撤销显示。

这不是零延迟承诺：默认捕获周期约 80 ms、界面检测周期 100 ms、绘制周期 50 ms。修改刷新周期、捕获耗时或游戏过渡动画仍会影响可观察到的响应时间。

## 过滤器

依据项目保存的[库街区大地图](https://www.kurobbs.com/mc/map/)官方目录 `Assets/KuroMap/catalogs/` 整理分类，而不再展示旧版本和各批同步数据的分类名称。已有 506 个唯一点位 ID 全部保留：

| 分类 | 类型数 |
| --- | ---: |
| 收集物 | 18 |
| 探索 | 51 |
| 采集物 | 91 |
| 敌人 | 141 |
| 强敌 | 71 |
| 挑战 | 38 |
| NPC及服务点 | 54 |
| BOSS | 42 |

默认打开收集物，提供分类选择、名称搜索、仅看已选、全选当前结果和取消当前结果。角色养成（61 组）和武器养成（121 组）复用相同的材料开关，也可搜索名称、角色缩写或材料名。中文显示官方名称，已有英文译名保留，缺少英文译名时显示官方名称而不是内部 ID。

同名但不同 ID 的点位保留独立开关。跨地图分类数字 ID 可能冲突，按语义分类归并；未审批点位不会因分类目录收录就自动开放。分类元数据损坏时保留原点位到补充分类并显示提示。

批量操作只改当前筛选结果，使用一次原子保存和一次核心命令；保留其他分类、旧版本选择和未知旧键。保存失败不改原文件。复选框仅响应用户点击，容器复用或绑定刷新不会误写选择。

## 诊断布局

截图开关从诊断卡片顶栏移到独立设置行，标题与开关状态不再叠放。诊断项默认展开；说明、按钮和状态文字可换行。过滤页与诊断页使用各自的滚动区域，避免外层滚动让内容高度失去约束。
