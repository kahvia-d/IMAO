# F8 无活动路线时打开附近攻略

用户确认没有活动路线，希望 F8 查看附近点位。此前快捷键事件能够进入攻略协调器，但协调器只查询 `markerGetRouteGuide`；没有路线目标时直接关闭待打开会话，键盘路径没有提示。

修复后的键盘行为：

- 已打开攻略或候选窗口：再次按 F8 关闭。
- 有活动路线目标：仍查询最新目标并打开对应攻略。
- 没有活动路线目标：通过 `markerGetNearbyGuide` 获取附近点位列表，选中后查看攻略。
- 定位不可用或附近没有符合筛选的未完成点位：沿用附近点位模块的明确提示。

附近查询复用已有的场景、定位时效、游戏窗口身份、焦点、筛选版本和完成状态检查，以及候选提交时的再次验证。没有放宽位置有效性要求。RPC 返回关联的候选结果，不发送独立的候选弹窗事件；前端确认打开会话仍然有效后才展示，避免再次按 F8 取消后迟到结果重新弹窗。既有手柄和完成点位事件保持原有发布方式。
