# 2026.9.17.5

修复一个问题：刚更新完程序后打开设置检查更新，仍然会提示「发现可安装的地图资源更新」，而且点「下载并安装地图资源」会把程序本来就自带的地图资源重新下载一遍（约 610 MB）。现在没有实际内容变化时不会再提示更新，也不会重复下载。

如果你还停留在更早的版本、点击「检查更新」会出现「拒绝旧清单或同一清单序号下的不同内容」，请先按上一条公告恢复：完全退出软件（托盘图标也退出）→ 删除 `%LOCALAPPDATA%\IMao-WinUI\ResourceUpdates\update-state.json` → 重新打开软件，再进入 设置 → 版本与地图资源，点击「检查更新」。
