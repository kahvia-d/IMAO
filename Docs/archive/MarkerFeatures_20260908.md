# 重叠点位、攻略与本地完成记录

更新日期：2026-09-08。

当前功能处理相近点位被遮挡、同一位置无法选择具体点位，以及完成记录的本地保存问题。每个点位保留原始身份、坐标、类别和独立完成状态；公开攻略仍可在线读取，完成与撤销只保存在本地。

## 1. 地图中的重叠点位

大地图与小地图根据当前屏幕上的图标范围分组。分组图标上的数字表示这组当前参与显示的点位数量，筛选或显示已完成点的设置会影响这个数量。

大地图操作：

| 操作 | 结果 |
| --- | --- |
| 鼠标在重叠图标上停留 350 毫秒 | 展开这组点位 |
| 左键点击重叠图标 | 立即展开这组点位 |
| 组内不超过 8 个点 | 围绕原位置呈环形展开，连接线指向原位置 |
| 组内超过 8 个点 | 显示分页列表，每页 8 个点，可前后翻页 |
| 左键点击一个具体点位 | 打开该点的攻略窗口 |
| 右键点击一个具体点位 | 切换该点的完成状态；已完成点可撤销 |
| 按 Esc、点击空白处或滚动地图 | 收起展开状态；滚轮仍交给游戏地图处理 |

分组使用真实成员点作为锚点，成员顺序按稳定身份排列。它不会修改原始地图坐标，也不会把一串相邻点无限连成一个跨越很远的组。环形展开和列表中的位移只属于显示层。

同坐标的点不等于重复数据。例如一个位置可以同时有隙声蝶与定风铎，或同一挑战的多种潮汐之遗。分层字段也可能缺失，因此不能用“同类且足够近”或“楼层字段相同”作为删除、合并完成状态的依据。

小地图显示数量角标，并保留以玩家附近点位为对象的 Z 键入口。它不使用大地图的鼠标展开交互。

## 2. Z 键附近候选

Z 键从当前呈现的小地图帧中查找靠近中心、尚未完成的点位。当前候选范围为投影到屏幕后距小地图中心小于 10 像素，不能把这个数值解释为游戏中的距离单位。

- 没有候选时不更改任何完成记录。
- 恰好一个候选时，将该点标记完成。
- 存在多个候选时，打开候选窗口，由用户选择具体点位查看攻略并标记；不会一次完成整组。
- 候选窗口支持继续加载，每批最多 100 个点。切换场景、本地档案或候选版本后，旧候选不能继续使用。

大地图鼠标操作只接收有效标记区域中的完整点击。拖动、过期显示帧或焦点变化不会触发完成操作。点击时的档案身份会随操作保留，旧点击不能落到其他本地档案。

## 3. 点位攻略

攻略窗口先读取随项目发布的本地名称、文字说明和分层信息，再获取库街区公开图文详情。查看公开攻略无需登录。

窗口提供：

- 文字说明、来源和分层提示；
- 图片前后切换、放大与缩放；
- 标记完成、撤销完成；
- 刷新攻略、打开对应库街区点位或攻略链接。

攻略窗口拥有自己的输入焦点，图片缩放和内容滚动在窗口内处理。切换点位或隐藏窗口会取消旧的加载任务，迟到结果不能覆盖新选择。

缓存规则：

| 内容 | 当前规则 |
| --- | --- |
| 本地说明 | 从 `Assets/KuroMap/states/state-{stateId}.json` 按地图延迟加载 |
| 在线图文详情 | 正常缓存有效期 24 小时；主动刷新跳过有效期判断 |
| 在线详情获取失败 | 有旧缓存则显示旧缓存，否则显示本地说明 |
| 图片 | 按地址摘要缓存，有效期 30 天，单张上限 12 MiB |
| 图片缓存总量 | 按文件时间保留较新的图片，目标上限 256 MiB |
| 在线详情响应 | 上限 2 MiB |

图片下载限定到库街区域名的 HTTPS 地址，并校验媒体类型与文件签名。外部攻略链接由用户点击后交给系统浏览器打开；在线文本不会作为网页脚本执行。公开攻略请求不携带登录凭据，也不会修改完成记录。

## 4. 本地完成、撤销与自动保存

大地图中右键点击具体点位可以切换完成状态；攻略窗口也提供“标记完成”和“撤销完成”。Z 键存在多个候选时，先选择具体点位，再操作其独立记录。

每次完成或撤销会写入当前本地档案，无需另点保存。文件采用原子替换写入，下一次启动继续读取已保存记录。点位 ID 全程按字符串处理；同位置的不同点位拥有独立状态，显示筛选或重叠展开不会合并它们。

当前版本没有库街区账号连接、云端进度上传、下载、比较或后台同步入口。点位完成记录不会因查看公开攻略而发送到网站；断网时仍可标记、撤销，并查看已缓存或随项目发布的攻略内容。

## 5. 数据位置与备份

用户数据根目录为 `%LOCALAPPDATA%\IMao-WinUI`：

| 路径 | 用途 |
| --- | --- |
| `SavedPoints/profiles/local.json` | 默认本地完成档案 |
| `SavedPoints/profiles/kuro_{userId}.json` | 旧版本已使用的独立档案，当前继续作为本地文件读取和保存 |
| `SavedPoints/account_1.json` | 更早版本的完成记录迁移来源，原文件保留 |
| `kuromap-accounts.json` | 若旧版本留下此文件，仅用于读取 `ActiveProfile`，保持原来的本地档案选择 |
| `GuideCache/details`、`GuideCache/images` | 公开攻略详情与图片缓存，可重新获取 |

备份前先正常关闭工具，然后复制整个 `SavedPoints` 文件夹。如存在旧版 `kuromap-accounts.json`，一并备份，以保留原档案选择。请保留文件名和目录结构，不要把多个档案内容拼接为一个文件。

恢复或换电脑时，先备份目标位置已有的文件，关闭工具后将备份放回上述对应位置。迁移本地完成记录依赖这些档案文件，不需要登录或复制浏览器会话。攻略缓存可以自行保留，也可以由工具重新获取。

## 6. 旧版本档案兼容

为避免移除账号功能后看不到原有完成记录，CoreHost 使用 `LocalMarkerProfileSelection` 只读旧 `kuromap-accounts.json` 中的 `ActiveProfile`。允许的选择是 `local` 或 `kuro_` 加合法数字 ID；随后继续打开同名的 `SavedPoints/profiles/{profileId}.json`。

此读取不登录账号，不读取 Token、账户列表或登录方式，也不会合并、复制或删除不同档案。`kuro_{userId}` 在当前版本中只是保留的本地档案名称，不能据此判断存在在线账号连接。没有旧选择文件时使用默认 `local` 档案；旧选择无法读取或格式无效时给出提示并回到 `local`，原文件保持不变。

旧档案可能仍含 `syncStates`、`remoteCompleted`、`pending` 等元字段。它们仅为磁盘格式兼容保留，不代表存在待上传工作。当前没有云端客户端、后台同步 worker 或浏览器桥接进程；不能因这些旧字段而启动网络同步或改写其他档案。

移除功能不主动清理用户的旧配置、完成档案、浏览器数据、注册表或 Windows 凭据保管库。当前工具不会访问这些旧登录凭据。

## 7. 维护入口

| 代码 | 职责 |
| --- | --- |
| `IMao-Core/src/Runtime/MarkerLayout.h` | 屏幕分组和点击/拖动判定 |
| `IMao-Core/src/ImguiDraw/Items/DrawMarkerInteraction.cpp` | 大地图角标、展开、分页、输入命中 |
| `IMao-Core/src/ImguiDraw/Items/DrawItemOnMinMap.cpp` | 小地图角标与 Z 键候选 |
| `IMao-Core/src/Runtime/MarkerCompletionStore.h` | 本地档案、独立完成状态与原子保存 |
| `IMao-Core/src/ImguiDraw/Items/DrawItemBase.cpp` | 点位身份、完成命令与状态事件 |
| `IMao-WinUI/Services/CoreHostService.cs` | 启动核心、恢复当前本地档案并转发标记命令 |
| `IMao-WinUI/Services/LocalMarkerProfileSelection.cs` | 只读旧 `ActiveProfile` 的兼容选择逻辑 |
| `IMao-WinUI/Services/MarkerDetailService.cs` | 公开攻略读取、响应校验与缓存 |
| `IMao-WinUI/Services/MarkerGuideCoordinator.cs` | 点位选择、候选窗口、攻略窗口和本地完成状态刷新 |
| `IMao-WinUI/Views/MarkerGuideWindow.cs` | 攻略内容、图片与本地完成/撤销交互 |

维护时应保留以下约束：

- 点位 ID 不经过浮点数或 JavaScript 普通数值转换。
- 原始类别 `sx·qq`、`sx·lgn` 与运行时别名 `sx_qq`、`sx_lgn` 仅在资源或公开攻略接口边界转换。
- 本地完成快照每页最多 500 条；跨页修订变化时重新读取，不能拼接不同版本的数据。
- Z 键候选分页使用独立候选修订号，与大地图每页 8 个点的展开列表分别维护。
- 切换点位或窗口关闭后，旧攻略请求不得覆盖新选择；保存与公开网络请求相互独立。
- 保留已有档案之间的隔离，不能把移除账号功能解释为要合并或重置所有完成记录。
- `Assets/KuroMap` 中的点位、分类和攻略资源仍被本地地图与公开攻略使用，不能随旧浏览器功能一起删除。

公开攻略仍使用库街区网页的公开接口，字段和图片地址可能随站点更新变化。网络异常时优先使用已有缓存和本地说明；修复兼容问题时不应放宽地址、媒体格式或响应大小校验。
