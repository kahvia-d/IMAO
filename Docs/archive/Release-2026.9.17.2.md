# 2026.9.17.2 库街区点位进度同步

本版本新增鸣潮库街区大地图点位完成状态的双向同步，并在设置页提供自动同步。相对 2026.9.17.1，本版修正自动同步的结果通知没有回到界面线程的问题（打开设置页时自动同步会失败）。

- 通过浏览器扩展 + 原生消息桥接读取库街区账号的已完成点位，本地点位进度与之比较后按并集补齐：库街区独有的完成点拉进本地，本地独有的完成点写回库街区。
- 同步只做补齐，不会因为某一边缺少而取消任何点位。预览表按“本地点位数 / 待推送 / 云端点位数 / 待拉取”展示，并可切换是否显示两边都已同步的数量。
- 差异按区域列出，编号小的区域在前；“大世界”合并显示并支持展开查看包含的地区。可切换是否显示没有差异的区域。
- 新增“自动同步”开关：打开后启动约 30 秒跑第一次，之后每 10 分钟一次；失败按 1/2/4/8/16 分钟退避，上限 30 分钟，成功即恢复；手动预览或应用会重置计时。开关状态与最近一次结果都会保留在本机设置里。
- 桌面端启动时会为当前 Windows 用户注册浏览器桥接，设置页可一键注册/修复，也可断开库街区连接（只删除本机凭据，不影响本地点位进度、路线和设置）。
- 上传使用官方 `changeStatus` 接口（`status=1` 完成、`status=0` 取消），已用真实账号验证幂等，写入结果未知时可安全重试。
- 程序图标更新为新的 IMao 图标。

写入接口、读取接口与扩展 ID 均在本次开发中实测通过：读接口为账号级完成点集合，写接口往返可逆且重复调用不产生重复数据。未验证的边界：批量上传（只实测单点往返）、多标签页同时连接、自动同步在真实账号上的长时间连续运行，以及真实浏览器与游戏内的完整交互验收。
