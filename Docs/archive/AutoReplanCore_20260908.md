# 实时路线重排核心

实时规划默认关闭。两个界面入口共用 `autoReplanEnabled` 配置，核心通过 `SetAutoReplanEnabled` 接收已保存配置。

核心每 500ms 检查一次，最短 2 秒计算一次；玩家移动超过剩余目标正最近邻距离中位数的 10%，或进度/导航状态变化时重新评估。距离始终使用地图相对坐标，不代表游戏米数。距离尺度按剩余点成员集合缓存。

新旧访问顺序以同一个最新玩家位置比较。收益达到旧总长度 1% 与上述距离尺度 10% 中的较大值才更新。换当前目标还需两次相隔至少 2 秒的结果一致、8 秒切换冷却，以及当前目标不在小地图 10px 的附近范围。处于选点、人工预览计算、打开大地图、暂停或定位失效时停止自动提交。

位置来自 App 确认的视觉定位，冻结源帧序号、原始捕获时间、坐标、场景、会话和连续性世代。最新捕获须在 250ms 内，定位源帧须在 750ms 内；至少三个独立确认帧且跨度不少于 200ms。重复呈现旧帧和单独 OCR 回退不能触发换目标。默认 80ms 周期需要第四帧才达到 240ms 稳定窗口。

计算使用独立后台线程和任务世代，不改变草稿。提交前复核最新位置、路线与进度身份、完成记录及收益；先原子保存，再发布新顺序。全部点 ID、完成点成员、跳过集合及撤销历史保留，只重排未处理的槽位。保存失败保留原路线。

自动换目标后，实线指向新目标，一条灰色虚线指向最近一次被替换的目标。新目标到固定小地图中心的实际呈现距离持续低于 10px 达 500ms 后，仅清除虚线提示，不完成目标。判定直接投影路线目标真实坐标，不依赖筛选清单。定位失效隐藏提示并重置到达计时；无关点位完成不清除提示。路线顺序与比较提示使用独立修订号过滤旧绘制帧。

## 离线验证入口

- `IMao-Core/tests/RoutePlanningTests.cpp`：原路线回归及新增纯策略测试，包含默认 80ms 稳定链、共同起点比较、冷却、10px 边界、持续到达、重复帧、全部身份保留及旧线段过滤。
- `IMao-Core/tests/RoutePlanningServiceTests.cpp`：直接编译真实 `RoutePlanningService.cpp`，仅在 `IMAO_ROUTE_SERVICE_TEST` 下替换外部标记/日志依赖。生产程序没有观察注入 IPC。测试使用隔离目录和 80ms 的真实时钟观察，覆盖启用后两次计算换目标、被占用文件保存失败及恢复、实际路线文件重新加载、完成/取消完成、跳过撤销、无关完成和到达不自动完成。
- 服务测试参数：第一个参数为隔离数据目录；第二个可选参数 `save-failure` 启用文件占用失败场景。不能使用真实用户路线目录。

本轮独立构建与日志在 `out/auto-replan-native/`。这些验证不等于实际游戏验收；实机仍需确认定位刷新、目标切换、虚实线显示及接近目标后的提示消失。

2026-09-08 本轮结果：独立路线回归退出 0，20 组 500 点求解 P95 18.2622ms、最大 19.1757ms；真实服务普通与文件占用场景均 `failures=0`。文件重新加载断言通过。五个修改的原生翻译单元进行独立语法检查，退出 0，保留既有数值转换警告。未使用该独立测试构建覆盖发布目录。
