# 标准 Xbox 手柄适配设计

> **最新行为以 [地图工具台与附近点位操作（2026-09-08）](../MapTools_20260908.md) 为准。** 当前大世界使用 LB+B 完成附近点、LB+X 打开附近攻略；大地图 LB 打开地图工具台，RB 打开独立助手。下文保留历史设计与验证记录，其中 L3 等旧键位不再作为当前使用说明。

日期：2026-09-08。状态：已实现体验版，默认关闭；真实手柄与游戏的冲突尚待实机验证。适用设备为没有独立背键的标准 Xbox 手柄。

## 体验方法

运行 `x64/Release/IMao-WinUI.exe`，在“使用指南 → Xbox 手柄适配（体验）”打开开关，设备保持“自动选择”即可。打开游戏大地图，回正摇杆并松开全部按键后，**按一下 LB 进入原有路线工具栏，按一下 RB 打开独立点位助手**，均在松开时执行。旧的肩键选择字段保留用于读取已有配置，当前入口采用固定分工，不再要求长按。

用方向键或左摇杆选择具体点，A 打开攻略，LB/RB 翻图，右摇杆滚动。详情页按住 X 0.6 秒只完成当前点；B 返回，列表页再按 B 退出并返回游戏。Y 打开路线菜单，跳过需要再确认。设置关闭立即停用输入，不等待核心通信结束。

普通探索画面中，**按下并松开左摇杆 L3 完成当前位置附近符合原 Z 键规则的点；L3 与 LB 组合切换当前路线目标攻略**。组合可先按任意一键，等待两键都松开才执行；用过组合后不会额外完成点位。攻略取得前台后直接用 LB/RB 翻页，B 关闭。L3 单击允许角色正在走动或转动镜头，不要求摇杆回正；其他按钮或扳机干扰会取消整次手势。

附近列表来自开图前的有效小地图定位及当前筛选，按真实地图距离排序；第一版最多显示 100 个、距离不超过 120 地图坐标单位的可见未完成点。缺少可信定位时仍可查看明确的路线目标，但不会推测附近点。这里的距离不是高度或米数。

## 1. 第一版范围与启用条件

当前版本覆盖原有路线工具栏、矩形框选、套索、明确点位攻略，以及普通探索中的完成和攻略快捷动作。普通探索只识别 L3 单独手势与 L3+LB 组合；A/B/X/Y、RB、方向键等不单独触发本项目动作。载具等未确认场景不应按探索画面的键位假设处理。

大地图入口固定为 **LB 路线工具栏、RB 独立助手**，必须先确认稳定大地图。L3 在大地图被游戏的“任务/位置追踪”占用，因此项目的大地图入口不使用 L3。L3 完成与 L3+LB 攻略只在新鲜、可观察的普通探索上下文及游戏前台生效。截图没有列出 L3+LB 的绑定，只能说明它是待实测的候选组合，不能据此保证游戏不存在冲突。体验开关默认关闭。

面板只在自己具有焦点时处理按键；游戏失焦后是否仍响应同一手柄，需要实机确认。微软 DirectXTK 文档描述了 XInput 的全局读取和应用自行忽略后台输入的要求；另一份 `XInputEnable` 文档注明 Windows 10 及以后此函数已废弃，系统会按窗口焦点自动启停手柄输入。不同输入后端、系统版本和游戏失焦处理行为需要实测，本项目调用读取或禁用 API 不构成对另一个游戏进程的独占保证；本实现不依赖 `XInputEnable` 截断游戏输入。[DirectXTK：Application focus](https://github.com/microsoft/DirectXTK/wiki/GamePad#application-focus)、[Microsoft Learn：XInputEnable](https://learn.microsoft.com/en-us/windows/win32/api/xinput/nf-xinput-xinputenable)

如果游戏在后台仍然响应同一手柄，当前模式验收不合格，功能继续关闭，等待后续可验证的输入隔离方案。增加长按时间、叠加组合键或只隐藏游戏画面，都不能替代输入隔离验证。

## 3. 面板操作

以下动作仅在工具面板上下文有效、面板具有焦点时开放。体验时需确认操作面板不会同时触发游戏动作。

| 按键 | 面板动作 | 限制 |
| --- | --- | --- |
| 方向键 / 左摇杆 | 移动选择 | 显示清楚的当前焦点；摇杆有死区，不因轻微漂移移动选择 |
| A | 展开重叠组、打开明确点位的攻略，或确认当前菜单项 | 先选一个具体点，不把整组作为完成对象 |
| B | 返回上一级；根层退出面板 | 取消尚未提交的操作；退出时经过输入释放步骤 |
| LB / RB | 攻略图片上一张 / 下一张 | 仅攻略及图片页有效，无图片时禁用 |
| 右摇杆 | 滚动内容；已放大图片时平移图片 | 不映射游戏镜头；进入放大视图使用可聚焦的界面按钮 |
| 按住 X 600 ms | 标记当前详情页的明确点位完成 | 显示按住进度；列表、重叠组、路线菜单中均禁用 |
| Y | 打开路线操作菜单 | 菜单提供暂停/继续、跳过、撤销跳过；Y 本身不直接跳过 |
| LT / RT、Menu / View / Guide、RS | 不额外分配 | 不利用“截图未见”推定空闲 |

完成操作锁定点位 ID、账号/进度档案、选择代次和原路线身份。按住期间换点、换账号、换场景、失焦或断连立即取消。每次按住最多提交一个点；即使保存后页面切到下一个点，继续按住 X 也不能再次完成，必须释放后重新按下。

保存成功后返回列表；若该点属于原活动路线，按现有规则推进该路线。保存失败时保留详情与错误提示，不关闭页面、不推进路线。完成动作固定写入“已完成”，不能再次按 X 就撤销已有完成状态；撤销应是另一个明确操作。

### 原有路线工具栏

LB 进入后，路线按钮仍显示在游戏地图原有位置，当前按钮显示高亮；左摇杆或方向键选择，A 松开确认，B 松开退出。输入由项目自己的透明窗口接收，原生工具栏沿用现有路线命令与选择校验。

选择“框选”或“套索”后，左摇杆移动虚拟光标，按住 A 拖动，达到 250 ms 后松开提交；短按不提交圈选。提交仍使用原有多边形筛选逻辑，只追加路线选点，不能把圈中的点批量标为完成。地图投影、场景、账号、焦点或输入时效变化时取消未提交圈选。选择“指定起点”时可移动光标后按 A 指定；完成圈选后返回移动工具，便于重新选择操作。

## 4. 目标来源与过渡状态

面板优先展示“路线当前目标”和“附近点位”。附近列表使用**打开大地图之前的可信玩家位置快照**，标明“打开地图前的位置”及快照状态；地图中心、当前视野中心或鼠标位置都不能代替玩家位置。

快照不可信、失效或场景不一致时，附近候选入口禁用并说明原因。仍可查看身份明确且账号匹配的路线目标攻略，但不能据此宣称玩家就在目标附近。

| 状态 | 允许行为 | 离开条件 |
| --- | --- | --- |
| 普通探索 | L3 松开请求完成；L3+LB 两键松开请求攻略 | 打开地图、失焦、画面证据失效、场景或账号变化 |
| 大地图 | LB 松开进入原有路线工具栏；RB 松开打开独立助手 | 进入相应工具、关闭地图或失焦 |
| 请求进入 | 打开面板并申请焦点，不执行面板动作 | 焦点条件满足，且全部输入释放后进入面板；否则取消 |
| 面板操作 | 仅分派上表中当前页面允许的动作 | 返回退出、失焦、地图上下文失效、场景/账号变化或游戏退出 |
| 保存中 | 锁定原点位，禁止重复提交 | 保存成功或失败；旧身份的结果不能作用于新选择 |
| 等待释放 / 停用 | 不产生工具动作 | 按键与扳机释放后接受新手势；地图和面板还需摇杆回到死区，普通探索允许持续移动；断连期间保持停用 |

进出面板、失焦、设备重连都必须清除长按计时、重复导航计时与旧按键状态，先释放再允许新按下。退出过渡完成后才恢复普通探索上下文，防止旧手势被项目再次解释。这里的工具状态管理不能替代对游戏实际响应的验证。

只绑定一个明确的活动手柄，不合并多个设备的输入。设备断连立即停用并取消待执行动作；重新连接后重新建立设备上下文，不能把另一只手柄的已按下状态接入当前操作。游戏退出、场景或账号变化使当前位置快照和未提交输入失效。

## 5. 与现有实现衔接

本版采用集中手柄采样与动作路由，按设备、页面、焦点和选择身份判断可执行动作，直接调用项目的点位、攻略与路线功能，**不模拟 Z、F8 等键盘按键**。现有键盘行为继续独立保留。

普通探索动作通过 `markerGamepadWorldAction` 传入线程安全队列，IPC 只返回已排队，不意味着完成成功。消费端在原有按键监控线程重新验证游戏前台、档案、窗口、上下文代次和新鲜的大世界画面证据；等待超过 250 ms 的请求丢弃。`completeCurrent` 另外要求当前小地图定位帧新鲜且可见，再原样调用 `SavePlayerNearItemPoint`：只有一个符合原有近点条件的候选才直接完成，多个候选保留明确选择。`toggleGuide` 不依赖新的玩家定位，发送带手柄来源的原 `markerGuideShortcut` 事件，绑定当时活动路线的当前目标及路线 ID；IPC 线程不读取可变 App 字段。

## 6. 启用前验收

构建和离线运行测试不能代替以下实机验收。体验版允许手动开启，这些实机项仍待验证。

| 验收项 | 通过要求 |
| --- | --- |
| 游戏独立响应 | 分别验证正常游戏、大地图、载具、工具面板前台和失焦状态；操作面板时游戏不攻击、闪避、移动、转镜头、切队员或执行地图动作。只证明工具收到输入不算通过 |
| 大地图入口与误判 | 分别确认 LB 工具栏与 RB 助手；稳定大地图外、短暂误识别或地图已关闭时不打开工具 |
| 探索快捷动作 | L3 单独松开只提交一次；L3+LB 只切换攻略，不能额外完成；移动中按 L3 可用，额外按钮、扳机及过期上下文均取消 |
| 原有路线工具栏 | 方向选项、A 确认、B 退出；框选和套索松开只追加选点，失焦、断流及地图变化不能提交残留圈选 |
| 焦点与按住过渡 | 在按住 A/B/X、摇杆偏转时进入、退出、切换窗口，均不产生遗留动作；新上下文必须等待全部释放 |
| 单点与保存 | 重叠点先选一个；只修改指定点位和账号；保存失败不推进；保存成功只推进原路线的对应目标 |
| X 持续按住 | 600 ms 只提交一次，页面切换、保存返回和下一目标出现均不能连续完成；换点或失焦取消尚未提交的长按 |
| 断连与重连 | 断连停止动作；重连与更换设备不继承按住状态；第二只手柄不能共同触发组合或确认 |
| 身份与定位变化 | 游戏退出、场景/账号变化使输入失效；无可信开图前快照时不产生附近点，不能把地图中心当玩家位置 |
| 路线菜单 | Y 只开菜单；跳过不写点位完成；撤销跳过只影响原路线，不能误操作另一条路线 |

通过上述验收并记录游戏版本、键位设置、手柄及连接方式后，再决定是否正式默认启用。体验中发现游戏后台仍响应手柄时，应关闭体验开关并记录冲突动作，以便调整输入方案。
