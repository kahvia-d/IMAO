# 2026.9.17.6

这一版解决"用工具时游戏掉帧、转视角忽快忽慢"的问题。

**操作延迟**

以前叠加层会持续接管鼠标事件，并且每秒重绘 30 次；处理鼠标事件和重绘是同一个线程，所以每一次重绘都会往后推游戏的输入，表现为转视角时忽快忽慢、点地图时反应迟钝。现在只有在地图上真正需要点击时才接管鼠标，平时的鼠标操作由游戏直接处理。

**画面捕获**

默认改用 Windows Graphics Capture。它不再要求游戏为截图额外渲染一帧：实测同一台机器上，游戏超过 100 毫秒的卡顿帧从每次会话出现数个降到 0，掉帧明显减少。如果某台机器上这种方式无法启动，程序会自动回退到原来的方式并给出提示，不需要手动处理；也可以在 设置 → 画面捕获方式 里手动切换。

**叠加层**

没有内容需要显示时不再反复重绘，并会把叠加层窗口隐藏起来，减少对游戏帧率的占用；采集与识别等后台线程的优先级也降到游戏之下，不再和游戏抢 CPU。

**图形兼容设置**

设置页的"应用窗口兼容设置"会写入一个对所有 Direct3D 程序生效的全局选项，之前没有恢复入口。现在同一页提供"恢复图形默认设置"，可以只撤销这一项，不影响其它的 Windows 图形偏好。
