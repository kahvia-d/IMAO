# 2026.9.17.4 修复无法更新的问题

本版本修复了一个导致部分玩家无法更新的问题：点击「检查更新」时会提示「拒绝旧清单或同一清单序号下的不同内容」，之后无论程序还是地图资源都装不上。更新到本版本后即可恢复正常。

如果你现在正卡在这个提示上，手动恢复只要三步：

1. 完全退出软件（托盘图标也要退出）。
2. 删除 `%LOCALAPPDATA%\IMao-WinUI\ResourceUpdates\update-state.json`。在文件资源管理器的地址栏粘贴 `%LOCALAPPDATA%\IMao-WinUI\ResourceUpdates` 就能找到它。
3. 重新打开软件，进入 设置 → 版本与地图资源，点击「检查更新」。

这个文件只保存更新检查记录，删除它不会影响点位进度、路线、筛选和个人设置。更新到本版本之后，设置里也会多出一个「修复更新状态」按钮，再遇到同类情况点一下即可，不必再手动删文件。
