# 中央海面导致的大地图定位失败

用户已实地确认前一轮怀疑的礁石与宝箱位置存在，本轮处理地形稀疏时的匹配覆盖范围。

旧管线统一截取 1600×900 基准画面的中央 350×350 区域。用户这张 2560×1440 截图的该区域全为海面，离线回放只有 2 个描述子匹配、0 个几何内点；静止帧桥接和两个小幅平移也均失败。

取样范围改为基准画面 x=160..1440、y=135..765 的居中矩形，避开边缘 UI，同时包含周边海岸。绝对定位先在其中原大小的中央区域快速尝试，失败后使用整个取样范围。匹配特征坐标还原到完整矩形，结果四角、标记投影、点击位置和帧间运动使用同一几何约定。旧方形比例检查改为对应图像的宽高比检查；惯性计算保留原 350 单位标定。没有放宽匹配或 RANSAC 门槛。
