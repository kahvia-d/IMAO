# 库街区进度同步扩展：手动安装（商店审核通过前）

Edge 加载项商店的审核还在进行中。在这之前可以手动加载**同一份代码**：`manifest.json` 里固定了发布公钥，所以手动加载得到的扩展 ID 与将来的商店版完全相同（`ohmikfaeobbffhlhoocklplniobcfdbg`），桌面端的桥接不需要任何额外改动。

## 前提

- IMao 桌面程序 **2026.9.17.6 或更高**（程序包里自带 `KuroSyncBridge.exe`）。
- Edge 或 Chrome（Windows）。两者步骤相同，只是扩展管理页地址不同。

## 步骤

1. **注册桥接**：打开 IMao → **设置 → 库街区点位进度同步** → 点「注册/修复浏览器桥接」。
   状态行显示「浏览器桥接已注册（扩展 ID ohmik…）」即成功。若提示找不到 `KuroSyncBridge.exe`，说明用的不是完整程序包，请重新下载完整包。
2. **下载扩展**：从 https://github.com/kahvia-d/WWMAP-TOOLS/releases/tag/ext-v0.1.1 下载 `IMao-KuroMapSync-0.1.1.zip`。
3. **解压到固定目录**：例如 `%LOCALAPPDATA%\IMao-WinUI\KuroMapSync\`。
   不要解压到「下载」文件夹——清理后就失效了。解压完成后，该目录下应当**直接**能看到 `manifest.json`。
4. **加载扩展**：地址栏打开 `edge://extensions`（Chrome 是 `chrome://extensions`）→ 打开「开发人员模式」→ 点「加载解压缩的扩展」→ 选中第 3 步的目录。
5. **连接**：打开并登录 https://www.kurobbs.com/mc/map/ → 刷新页面 → 点扩展图标 → 「连接桌面端」。
   提示「已连接到同步档案 …」即成功；档案 ID 记下来备用。
6. **同步**：回到 IMao → 设置 → 库街区点位进度同步 → 先「预览同步」看两边差异 → 再「应用同步」。
   同步只做并集：库街区独有的完成点拉进本地，本地独有的写回库街区，两边都不会取消任何点位。打开「自动同步」后，游戏内标记完成会立即推送，并每 10 分钟整体补齐一次。

## 要接受的代价

- 浏览器会显示「开发人员模式扩展」提示；Edge/Chrome 重启后可能提示「停用开发人员模式扩展」，选择保留即可。
- **不会自动更新**：扩展更新时需要重新下载 zip、覆盖目录内容，再到扩展管理页点「重新加载」。
- 商店版过审后，建议卸载手动版并改从商店安装。扩展 ID 相同，桌面端的凭据与同步档案不受影响。

## 常见问题

- **加载后扩展 ID 不是 `ohmik…` 开头**：选错目录了（多半选了 zip 解压出来的上一层）。所选目录里必须**直接**有 `manifest.json`。
- **点「连接桌面端」提示找不到宿主**：桥接没注册（回到步骤 1），或者浏览器与桌面程序不在同一个 Windows 用户下。
- **提示「未找到可用登录会话」**：先在库街区地图页完成登录，再刷新页面重试。
- **换电脑或换浏览器**：重复步骤 1–5 即可，同步档案由档案 ID 对应。

## 数据与隐私

扩展只读取库街区地图页面自身存放的登录凭据与账号 ID，不做任何网络请求，数据只通过浏览器官方的 Native Messaging 通道交给本机桌面程序，由桌面程序以 Windows DPAPI 加密保存在当前 Windows 用户下。完整说明见 [KuroMapSyncPrivacy.md](KuroMapSyncPrivacy.md)；商店上架材料见 [KuroMapSyncStoreListing.md](KuroMapSyncStoreListing.md)。
