# 2026.9.18.2

这一版修掉一个会让工具完全用不了的故障，并把叠加层的默认设置改回上一版之前的样子。

**修复：点「开始探索」后一直停在"等待定位"**

当画面捕获回退到 BitBlt 时，工具一帧画面都发布不出去，游戏内状态条会一直显示
「等待定位 / 等待游戏界面」，标记也不会出现。触发条件是 Windows Graphics Capture
启动失败（部分机器和系统版本会失败）而自动改用 BitBlt 的情况。

**改回：叠加层默认使用「分层窗口」**

2026.9.18.1 把叠加层的呈现方式改成了 DirectComposition，理由是"帧率更高"。
这个理由**不成立**，我们已经撤回：那次对比测的不是随后发布的那个窗口，
而且实验方法本身不严谨。所以：

- 默认改回 **分层窗口**（也就是 2026.9.18.1 之前所有人一直在用的方式），
  升级后会自动切回去，**不需要你手动改**；
- **DirectComposition 仍然保留**：设置 → 叠加层呈现方式 里可以手动选，但不再推荐；
- 同时修好了一个显示错误：这一版之前，设置里两个选项的名称和实际生效的方式是**反的**
  （选了 DirectComposition 其实得到的是分层窗口）。

**画面捕获方式不变**，仍是 Windows Graphics Capture 优先、失败时自动回退 BitBlt。
