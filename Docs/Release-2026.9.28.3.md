# 2026.9.28.3

- 修复：大地图标记**一闪一闪**的另一个来源——窗口焦点。此前游戏窗口只要有一帧不是前台（切一下窗口、弹个通知，或者本机就是会时不时报"不是前台"），整层标记就会在那一帧被撤掉，焦点回来再画上；在会反复丢焦点的机器上，标记因此一直通断（玩家日志里最极端的一次是开着地图黑了 48 秒）。现在标记层会容忍短暂的焦点丢失，只有焦点确实离开一段时间才撤掉。
- 修复：焦点丢失时不再把已经算好的大地图浮层一起收走，也不会因此把整屏浮层缩成小地图面板。
- 修复：工具窗口与游戏之间交接焦点时用于保住地图画面的那道保护，此前要求"当前帧仍有焦点"才会生效，导致它在真正丢焦点的那一帧正好失效；现在它按已经带容忍的判定工作。
- 提醒：程序版本号与地图资源版本号相互独立，本次只更新程序，地图资源沿用的是 2026.9.28.1 那一套，不需要重复下载资源。
