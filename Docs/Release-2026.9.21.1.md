# 2026.9.21.1

## 小地图定位

- 局部追踪丢失后不再长时间保持静止。进入水面、平地等缺少特征的区域时，程序以每秒 4 次的频率读取
  游戏左下角坐标，用于接续定位，取代此前冻结十余秒后再跳变的行为。
- 坐标读数中 x 与 y 之间缺少逗号的情况（实测约占飞行状态下读数的六成）现可正确切分使用，
  读数可用率由 42% 提升至 82%。
- 明显异常的读数（丢失负号、瓦片错位、跳变过大）会被丢弃。判定依据为最近一段真实轨迹，
  并采用实测的飞行速度上限（约 100 单位/秒）。
- 定位短暂中断时，小地图标记按轨迹外推继续移动；外推 1 秒的误差约为 7 个单位。
  超过 2 秒未取得新的定位结果时不再绘制标记，避免标记停留在原处反复闪烁。

## 地图标记

- 打开一次大地图即可确定所在区域；在此之前，状态栏提示「请打开一次大地图以确定所在区域」。
- 附近点位列表的移出范围加大，位于范围边缘的点位不再反复出现与消失。

## 新增游戏内操作：开始 / 停止探索

- 手柄：按住 LB 再按 Start 键；键盘：默认为 F9，可在设置中修改。
- 两者与首页的「开始探索 / 停止探索」按钮等价：未在探索时按下即开始探索，探索中按下即停止探索。
- 设置页「键盘快捷键」新增「开始/停止探索」一项，并注明对应的手柄与键盘操作。

## 附近点位、攻略图与手柄

- 完成点位与查看攻略的触发范围改为设置项（设置页「完成点位触发范围」「查看攻略触发范围」，
  默认 15 像素，可调范围 5–120，修改后立即生效）。按键作用于范围内距离玩家箭头最近的点位；
  仅在两个点位的图标于小地图上相互遮挡时才列出候选，不再因范围内存在第二个点位而先行弹出列表。
- 候选列表支持连续处理：点击其中一项仅完成该点位，列表保持打开；同组点位可通过
  「一键收集本组全部点位」一次完成。
- 攻略大图改为独立窗口显示，居中于游戏窗口之上并保持置顶，可单独缩放与平移。
- 手柄键位调整：长按 A 完成当前点位（提前松开仍视为普通确认），长按 X 在完成列表中一次完成整组；
  X 用于放大攻略图（原为 A），LT / RT 缩放，左摇杆与方向键平移。
- 查看攻略键不再为唯一候选点弹出仅含一个选项的列表。
