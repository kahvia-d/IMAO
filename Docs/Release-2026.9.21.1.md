# 2026.9.21.1

**小地图定位：从"经常丢"到"能自己接回来"**

- 局部追踪跟丢时不再干等：进入无特征区（水面、平地）后，程序会**每秒 4 次**读取游戏左下角坐标，
  用它把位置接回来，而不是像以前那样冻结十几秒再跳一下。
- 读数里的**坐标被糊掉也能救回来**：实测飞行时约六成读数会丢掉 x/y 之间的逗号，
  现在这种读数会被正确切开使用，可用率从 42% 提到 82%。
- 明显错误的读数会被丢掉（丢负号、瓦片错位、跳变过大）：判据基于**最近一段真实轨迹**，
  并采用你实测的飞行速度（约 100 单位/秒上限），不再靠猜。
- 位置短暂丢失时，小地图上的标记会**按轨迹外推继续移动**（飞行速度下外推 1 秒误差约 7 单位），
  超过 2 秒没有任何新定位则**不显示标记**，而不是停在原地一闪一闪。

**更快、更稳的地图标记**

- 打开大地图一次即可确定所在区域，状态栏会直接提示"请打开一次大地图以确定所在区域"。
- 附近点位列表：离开范围需要更远才消失，不再在边界上忽隐忽现。

**新的快捷操作：游戏内开始 / 停止探索**

- **手柄：按住 LB 再按一下 Start 键**；**键盘：默认 F9**（可在设置里改）。
- 两者都等同于首页的「开始探索 / 停止探索」按钮：工具没在跑时按它可以**开始探索**，
  在跑时按它可以**停止探索**。
- 设置页「键盘快捷键」新增一行「开始/停止探索」，并写明两种手柄/键盘操作。
