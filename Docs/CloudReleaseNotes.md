# 2026.10.30.1

本次更新新增「查漏补缺」模式和路线非收集物点位完成状态手动重置功能，并修复批量取消筛选后勾选状态未更新的问题。

## ✨ 新增功能

### 查漏补缺模式

游戏大地图的「点位筛选」中，「仅看已选」右侧新增「查漏补缺」开关，无需创建路线或开启导航即可使用。

- 开启后，大小地图仅显示当前筛选中已收录的不可探测点位，首批收录 **378 个点位**。
- 原有分类、已完成点位显示及分层设置继续生效；关闭后恢复原筛选显示。
- 开关状态自动保存，重启、切换区域或退出导航后保留；已有路线和导航目标不受影响。
- 尚未收录的点位在此模式下隐藏，不代表这些点位能被探测仪发现。

查漏补缺点位取自 B 站 UP 主 **[又肝又氪ya](https://space.bilibili.com/650388538)** 的攻略整理，感谢作者授权与分享，欢迎关注催更。开启模式后，点位筛选页会显示作者署名。

### 手动重置路线非收集物点位完成状态

路线列表新增「重置完成状态」按钮，仅重置当前路线中的非收集物点位完成状态，收集物完成状态保持不变。当前路线包含敌人、采集物或每日刷新的自由点时可用，自动规划的混合路线也适用。

点击后弹出确认窗口，按名称列出本次重置的点位及数量。自由点按所选图标汇总，数字图标统一显示为「其它」。确认后，列出的点位恢复为未完成，路线内容保持不变。支持鼠标与手柄操作，弹窗默认选择「取消」。

## 🐛 问题修复

### 修复批量取消筛选后勾选状态不更新

修复单独点击过点位分类后，再点击「取消当前结果」，地图标记已经隐藏、分类勾选却仍然保留的问题。批量全选、取消及其他筛选变化现在会同步更新勾选状态。
