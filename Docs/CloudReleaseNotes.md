# 2026.10.12.1

### 无法启动的问题已修复

部分电脑上程序完全无法启动：双击没有任何反应，启动器只提示「程序在启动确认前退出。」，也不留下日志。本版已解决该问题，不需要额外安装任何运行库。

此类机器无法使用程序内更新，需从发行页获取完整程序包，解压到新目录后运行。

### 失败原因会写入日志

启动失败时，启动器在提示中给出失败代码与日志位置，并把失败代码与错误信息写入 `ProgramUpdates\launcher.log`；程序也会把启动过程逐步骤写入 `%LOCALAPPDATA%\IMao-WinUI\Logs\startup.log`。大地图上工具台图标点击或手柄 LB 未生效时，原因同样记入这两个目录下的日志。

### 库街区同步的桥接程序首次运行不再失败

浏览器扩展在主程序尚未注册桥接时先调用桥接程序，原先会因缺少配置文件直接退出；现在改用内置配置继续运行。
