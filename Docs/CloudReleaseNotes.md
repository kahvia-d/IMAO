# 2026.11.1.108

本次更新改善地图标记的显示稳定性，并新增 OCR 坐标识别 GPU 加速设置。

## ✨ 性能优化设置

设置页在「操作优化」下方新增「性能优化」栏目，提供「GPU 加速（OCR 坐标识别）」开关。

- 开启后可使用 GPU 进行 OCR 坐标识别；不支持或运行失败时自动回退到 CPU。
- 页面显示实际使用的识别后端及回退原因，便于确认加速是否生效。
- 选项自动保存，从托盘完全退出并重新打开软件后生效。GPU 加速可能增加显卡占用，实际表现因设备而异。

## 🐛 体验改善

- 改善小地图标记间歇闪烁、短暂消失的问题。
- 改善小地图标记抖动、漂移及部分更新滞后的情况。
- 优化地图点位筛选与标记刷新时的性能。
- 改善短时诊断采集的资源占用与稳定性。
