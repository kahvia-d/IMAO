# 2026.10.7.2

- 修正程序放在含中文（或其他非 ASCII 字符）的目录下时启动报错、点位与地图资源无法加载的问题。此前的安装路径会让资源加载过程中的一次告警变成整体失败，界面只留下一句 UTF-8 报错。
- 修正库街区点位进度同步漏掉已完成点位的问题：当库街区账号上已有、而本机记录本还不知道的完成点存在时，预览会误报"没有差异"，这些点位也一直不会被拉取；现在会如实显示为待拉取并同步到本地。
- 调整库街区首次同步的提示：账号上还没有已完成点位时，界面改为说明性提示而不是红色报错，并说明这通常是因为还没有在库街区大地图上标记过点位。

本版经维护者 maptest 验收（含中文路径安装与库街区同步）。云端构建、测试、打包与上传，本地仅签署小请求；签名格式和客户端更新验证协议保持兼容。
