# 2026.11.3.1

本次更新重构 IMAO 桌面界面，并新增云鸣潮浏览器窗口选择与画面识别支持。

## 界面更新

- 重新设计首页、路线、点位筛选、设置和帮助页面，统一导航、卡片布局与操作提示。
- 首页新增国度与区域收集进度，支持切换区域查看收集物完成情况。
- 调整点位筛选在窄窗口中的布局，搜索、分类和角色／武器筛选可自动换行显示。
- 重新整理帮助内容，并更正 IMAO 开源仓库链接。

## 云鸣潮支持

- 新增「选择游戏窗口」入口，可选择云鸣潮浏览器窗口作为识别来源。
- 支持自动识别浏览器内的游戏画面区域。
- 完善 Chrome 和 Edge 浏览器扩展连接支持。

## 问题修复

- 优化首页进度读取，减少反复读取记录本带来的界面负担。
- 修复已完成点位总数不变时，区域收集进度可能未更新的问题。
- 修复切换到无可用数据的国度后仍显示上一国度统计的问题。
- 改善快速切换记录本时的进度显示，读取失败时显示明确提示。
