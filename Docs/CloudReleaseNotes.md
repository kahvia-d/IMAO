# 2026.11.20.1

本次更新全面优化日常探索与大地图的识别响应和系统资源占用，新增性能档位设置，并完善窗口托盘与地图资源启用体验。

- 设置中新增“性能与刷新档位”，提供流畅优先、均衡（推荐）与自定义三档，默认采用均衡档位，可按硬件情况在跟手度与系统占用之间自由选择。
- 优化日常探索与小地图跟随体验，按使用场景动态调节刷新节奏并减少重复计算，在提升小地图标点平滑度的同时显著降低探索过程中的 CPU 与内存占用。
- 优化打开大地图及切换地区时的首次定位速度，减少拖动、缩放和跨区切换时的等待时间，同时降低大地图静止时的后台占用，并针对 4K 等高分辨率优化大地图识别与运行表现。
- 按区域按需加载分层地图数据，并优化字体资源与手柄检测的后台开销，整体运行更轻量。
- 关闭主窗口时新增关闭方式选择，支持最小化至系统托盘并在后台继续运行，或直接退出程序，同时修复窗口还原与部分按钮悬停时的显示问题。
- 未删除的地图资源在关闭后重新启用时不再需要联网校验。
