# 2026.11.3.1

本次更新带来全新的桌面界面、区域收集进度展示与云鸣潮网页版支持。

## 界面更新

- 重新设计首页、路线、点位筛选、设置和帮助页面，统一导航、卡片布局与操作提示。
- 首页新增国度与区域收集进度，可按当前记录本查看各类收集物的完成数量和完成率。
- 设置和帮助页面增加分类导航，方便查找选项与使用说明。

## 云鸣潮支持

- 首页新增「选择游戏窗口」入口，可选择 Chrome 或 Edge 中的云鸣潮窗口开始探索，也可切回本地客户端。
- 自动识别浏览器内的游戏画面区域，无需手动框选；窗口大小或全屏状态变化后重新识别。

## 库街区同步

- 新增对 Chrome 商店版库街区同步扩展的连接支持，继续兼容 Edge 版扩展。
