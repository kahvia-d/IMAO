# 2026.10.24.1

本次更新修复了窗口模式下读不出坐标的问题，诊断页新增短时完整采集。

## 🐛 问题修复

### 修复窗口模式下读不出坐标

小地图画面颜色单一、地形特征很少而匹配失败时，程序会自动改读画面上的坐标来定位玩家。游戏以窗口模式运行时，此前读取坐标数字的位置存在偏差，可能读不出数字，定位也会失败。本版已修复这一问题。

## 🔧 功能改进

### 诊断页新增短时完整采集

诊断页可以开始一次最多 3 分钟的画面和识别结果采集，也可以随时提前停止。采集结束后可在同一页面打开采集文件夹，反馈问题时把整个文件夹一起提供即可。
