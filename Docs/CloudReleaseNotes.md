# 2026.10.19.1

### 坐标文字识别换用新的自训 YOLO 模型

坐标读数不再使用原来的 PaddleOCR 模型，改用本项目自行训练的新模型。新模型的正确识别明显增加，识别不出而放弃的情况大约少了一半，较难辨认的坐标行也更容易一次读出完整数值。

### 小地图特征不足时改用坐标读数继续定位

小地图画面颜色单一、地形特征很少时，画面特征匹配容易失败，点位与路线会整段消失。现在这类情况会改用 OCR 读出的坐标来定位，只要读数可信，点位、自由点和路线就继续正常显示。

### 图像匹配与坐标定位的切换更平顺

两种定位方式来回切换时，位置不再突然跳开或回弹；图像匹配恢复后能及时切回，坐标读数短暂中断时也能更快恢复显示。

### 大地图与小地图的点位标记不再闪烁

此前打开大地图后，点位标记会成片消失再重新出现，小地图上也有同样的间歇性闪烁。本版修复了这两处。
