# 2026.10.19.1

### 大地图与小地图的点位标记不再闪烁

此前打开大地图后，点位标记会成片消失再重新出现，小地图上也有同样的间歇性闪烁。本版已修复这两处：大地图与小地图的标记持续显示。

### 坐标读数显示更稳定

坐标读数在移动、转向与停顿之间的显示更连续，不再出现数值抖动或反向回跳；读数中断后恢复显示也更快。

### 坐标文本识别更可靠

坐标文本的可识别画面范围更广，识别不出而放弃的情况明显减少。

### 小地图地形不易辨认时不再停绘

小地图地形颜色淡、图案重复时，点位、自由点与路线顶点仍会正常显示，不再整段消失。
