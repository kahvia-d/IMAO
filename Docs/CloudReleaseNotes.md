# 2026.10.12.1

### 修复了少数电脑上完全打不开的问题

某些机器上程序根本起不来：双击没有任何反应，用 `IMao-Launcher.exe` 启动只会弹出「程序在启动确认前退出。」，也留不下任何日志。原因是启动时有一项**本程序从未使用**的可选功能，在缺少相应系统组件的机器上初始化失败并把整个进程一起带走；该功能已移除，**不需要额外安装任何运行库**。此前所有版本都受此影响，之前打不开的机器装这一版即可。

如果那台机器现在完全打不开，程序内更新用不上：请到发行页手动下载完整包，解压到**一个新目录**再运行。

### 启动失败会说明原因

启动失败时弹窗会给出子进程的退出码（例如 `0xC000027B`）与日志位置 `ProgramUpdates\launcher.log`；启动过程每一步也会写进 `%LOCALAPPDATA%\IMao-WinUI\Logs\startup.log`。把这两样发来就能定位，不必再靠截图猜。大地图上点工具台图标或按手柄 LB 没反应时，日志同样会记录原因——这一条目前是排查线索，不是修复。

### 库街区同步的桥接程序首次运行不再失败

浏览器扩展在主程序还没注册过桥接时先调用它，会因缺少配置文件直接退出；现在改用内置配置，首次同步不必先开一次主程序。
