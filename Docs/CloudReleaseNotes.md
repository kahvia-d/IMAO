# 2026.11.22.1

本次更新新增可选的 WebDAV 库街区登录凭证同步功能，重构库街区同步预览弹窗，并优化首页与设置页多处显示与交互细节。

- 设置页新增可选的 WebDAV 库街区登录凭证同步功能（默认关闭），支持使用自有 WebDAV 服务在多设备间端到端加密同步库街区大地图登录凭证，支持多账号隔离管理、启动自动拉取及凭证失效自动续期，并支持便携配置文本一键复制与粘贴，平时默认折叠保持界面简洁。
- 库街区同步预览改为居中独立弹窗展示，提供核心数量概览与按变更类型着色的区域明细表，可在弹窗内实时切换“显示已同步数”与“显示无差异区域”，同时修复无差异时仍强制展开全部区域的问题。
- 优化部分独立地图场景的大地图定位表现，提升单区域大地图识别准确率。
- 修复首页地区收集物进度卡片右侧数字裁切、设置页紧凑开关文字显示不全以及窗口内悬停偶发弹出“Alt+向左键”提示的问题，并为首页地区完成度与收集物进度条新增平滑展开动画。
