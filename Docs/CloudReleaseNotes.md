# 2026.10.22.1

本次更新降低了内存占用，改善了大地图点位较多时的鼠标卡顿，带来手绘路线的刷怪采集选择，并修正了手绘首点问题、减少退出时的偶发崩溃。

## 🚀 性能优化

### 降低内存占用

同时启用全部地区并持续探索时，内存占用比上一版明显减少；启动阶段也更省内存。

### 改善大地图点位较多时的鼠标卡顿

改善大地图打开后点位很多时鼠标移动与点击不顺畅的问题，点位越密集越容易遇到；本版已明显减少这类卡顿。

### 优化跨地区定位的响应速度

跨地区定位搜索失败时，点位与路线长时间没有更新的情况明显减少，能更快恢复显示。

## ✨ 新增功能

### 手绘路线可选择是否开启刷怪采集

新建非收集物类的手绘路线时，程序会先询问是否为此路线开启刷怪采集，可选择「开启并绘制」「不开启并绘制」或「取消」。开启后，导航到目标附近并停留片刻会自动标记完成、推进到下一个目标，不代替游戏内的战斗或拾取。选择随草稿保存，之后续画不再重复询问，修改已保存的路线会保留原设置；弹窗支持鼠标、键盘与手柄操作。

## 🔧 功能改进

### 新建手绘时隐藏原有导航

新建手绘时，大地图只显示正在绘制的内容，原有导航线及其标记会暂时隐藏，避免两条线重叠看不清。保存、放弃草稿或取消类型选择后恢复原样，小地图导航不受影响。

## 🐛 问题修复

### 修复手绘路线首点无法用鼠标绘制

修复开始手绘后鼠标无法点下第一个点、必须先按 Q 建点才能继续的问题。

### 减少退出或停止识别时的偶发崩溃

降低退出或停止识别阶段偶发崩溃的概率。
