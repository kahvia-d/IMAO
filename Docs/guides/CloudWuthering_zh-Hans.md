# 云鸣潮网页版使用与测试

1. 在 Chrome 或 Edge 打开云鸣潮，进入游戏画面。
2. 打开 IMAO 首页的“选择游戏窗口”，选择对应浏览器窗口，查看自动预览，然后点击“使用此窗口”。
3. 开始探索。无需框选游戏区域，也无需先全屏；窗口大小与全屏状态变化后会重新识别。
4. 切回本地游戏时，在同一入口选择“使用本地客户端”。更换窗口前先停止探索。

选择仅本次 IMAO 运行有效，重启后重新选择。窗口列表不包含最小化的窗口；如果没有出现，先恢复窗口并刷新列表。预览失败时保持云鸣潮标签可见，再刷新重试。

## 手动验收清单

- 普通窗口和全屏均能识别坐标、小地图，大地图点位与游戏地图对齐。
- 改变浏览器窗口尺寸、进入/退出网页全屏后，定位恢复且叠加没有工具栏偏移。
- 鼠标点位、手绘路线、手柄圆环选择与画面位置一致。
- 切到其他标签或最小化时隐藏叠加，回到云鸣潮后恢复；关闭窗口后停止。

有问题时记录浏览器类型、窗口/全屏状态、症状和发生时间。区域识别由程序修正，不需要玩家手动提供裁剪框。

2026-11-03 的验证记录确认了 Edge 窗口捕获与排除工具栏；该记录尚未给出完整 Chrome/Edge 游戏实测结论，见[采样记录](../research/CloudWutheringCaptureValidation_20261103.md)。本次文档整理没有补做游戏实测。云游戏画质、UI 缩放和视频压缩可能影响现有识别模型，准确率以实际探索结果为准。
