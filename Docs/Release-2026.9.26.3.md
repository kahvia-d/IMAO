# 2026.9.26.3

- 修复填写了 Mirror酱 CDK 时程序更新失败的问题：镜像提供的是只含变化文件的增量包，程序在下载分片补齐其余文件时会撞上镜像已经写好的同名文件而中止，提示「文件已存在」。现在同名且内容一致的文件会被正确复用。
- 修复更新体积较大时设置页接近无响应的现象：进度上报过于密集，且解压与校验的工作占用了界面线程。现在进度按节流显示，更新的准备工作在后台完成。
- 「Mirror酱 提供的是完整程序包（约 1 GB），是否继续」这一确认框选择取消时，之前会直接结束更新；现在改为改用 GitHub 分片继续。
- 镜像下载中途停止响应时不再无限等待：连续 45 秒没有收到数据就改用其他来源；镜像下载中断留下的临时文件也会在下一次准备更新时清理（此前最多可残留约 1 GB）。
- 说明：仍在使用 2026.9.26.2 或更早版本、并且填写了 Mirror酱 CDK 的玩家，若更新时出现「文件已存在」而中断，请先在 设置 →「版本与地图资源」中清除 CDK 再重试；升级到本版本后不再需要这样做。
