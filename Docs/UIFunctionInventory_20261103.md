## 2. 不丢功能的新分组（设计提议）

四个主入口固定使用「首页、路线、点位筛选、设置」，诊断与帮助保留辅助入口。

| 新入口 | 页面首层 | 次级分组/渐进展开 |
|---|---|---|
| 首页 | 开始/停止、游戏来源、运行状态、当前路线、点位摘要 | 窗口选择、重新连接；地图图形只是示意，非新增地图编辑器 |
| 路线 | 合集、路线列表、导入/导出、批量管理 | 游戏内操作说明单独展开，明确选点/导航仍在游戏内 |
| 点位筛选 | 搜索、分类、角色/武器、已选、结果列表 | 同步异常出现时显示，正常时只留短状态 |
| 设置 | 显示；操作；记录与同步；地图与更新；高级 | 显示含大小地图与状态提示；操作含按键、手柄、触发范围；高级含捕获、性能、兼容 |
| 诊断 | 状态、日志、问题采集 | 性能对照收在高级诊断，不挤占日常界面 |
| 帮助 | 入门、快捷操作、常见操作、关于 | 旧数据恢复独立可发现入口，避免埋在长篇说明中 |

## 3. 文字整理原则

- 功能名使用直接动宾词，不再使用营地、航海桌等隐喻。
- 每组「标题 + 一句必要说明」，长篇解释放详情，不删除影响操作判断的限制。
- 保留语义差别：停止探索不等于暂停导航；取消筛选不等于撤销完成；删除路线不删除点位进度；停用区域不等于删除资源。
- 清楚区分本地记录本、库街区账号、地图资源，避免统一叫“数据”。
- 状态文案说明「正在做什么 / 结果 / 下一步」，不在普通页面展示内部技术过程。
- 涉及同步、删除、回退、恢复等操作保留确认和影响说明；草图只展示，不执行。
- 技术名 BitBlt、WGC、DirectComposition 保留在高级设置，不擅自声称性能更好。

| 当前表述/分散叫法 | 草图统一建议 | 保留的说明 |
|---|---|---|
| 概览 / 首页 | 首页 | 首页名称按本次用户要求 |
| 自动重排 / 实时规划 / 偏离路线时自动重排剩余目标 | 自动重排路线 | 偏离时调整剩余目标顺序 |
| 状态条 · 小地图 / 状态条 · 大地图 | 小地图状态条 / 大地图状态条 | 两项独立开关 |
| 取消当前结果 | 取消选择当前结果 | 仅取消类型勾选，不修改完成记录 |
| 回退上一版 | 回退地图资源 | 与回退程序分开 |
| 新增 / 修改 / 删除（记录本区） | 新建记录本 / 修改记录本 / 删除记录本 | 删除保留可恢复副本 |
| GPU 加速（OCR 坐标识别） | 坐标识别 GPU 加速 | 重启生效、可能回退 CPU |
| 导出体检 | 导出记录本检查报告 | 名称为提议，真实行为不变 |

## 4. 状态与边界

草图入口：[`design/style-lab/index.html`](../design/style-lab/index.html)，可双击离线打开。顶部五个按钮切换风格，「功能清单」可检索本文的 44 组功能。旧 `design/pixel-camp` 保留用于对照，不覆盖旧方案。

草图共用功能内容和会话状态，切换五种风格不会更换路线、点位或设置。桌面六页均有呈现；低频功能在设置分组、帮助和功能清单中可查。游戏内完整交互不在 HTML 重做，仅以单独标记的操作清单呈现，避免假装已迁入桌面。

五种方向：精密像素工具；地图图例＋战术终端；黑白单色＋机能街头；声波频谱＋游戏 HUD；透明电子设备＋极简猫咪品牌。比较保持相同内容、布局与操作，变化集中在边角、纹理、字体节奏、图形线条、色彩、状态标记、材质，而不是换几张背景图。

待核实：`SuggestionDialog.xaml` 写“没有图片/文字引导”，与现有 `MarkerGuideWindow.cs` 图文功能并存；搜索未找到旧提示页调用入口。用户表示不清楚该内容。本轮不判定实现或文档谁错，不修改原文件，不采纳该旧文案。其他帮助中出现的入口名称差异仅登记为待统一文案，不据此改变功能。

## 6. 草图验证与限制

- `node --check` 检查 `app.js`、`inventory.js`；`git diff --check`。
- 浏览器检查六页、五个设置分组、五种主题的首页文本一致性。
- 检查主题切换保留探索状态、筛选勾选和设置开关；路线选择/批量全选、模拟同步预览、模拟采集、清单搜索可用。
- 所有“下载、文件、删除、系统、凭据”等入口仅为流程说明；没有以成功通知冒充真实执行。
- 仅本地 HTML/CSS/JS/SVG，无安装、字体下载和构建依赖。模拟数据不是推荐参数或实际游戏状态。
- 尚非生产实现：拖动排序、完整导入导出、账号同步、游戏内选点与导航不在草图内执行。
