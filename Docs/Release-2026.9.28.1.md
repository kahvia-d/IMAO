# 2026.9.28.1

- 新增「刷怪采集」模式（路线工具栏，游戏内大地图的「路径自动规划」窗口里）。开启后你只要跟着路线走，走到目标附近停住约半秒，程序就把那个点替你标成已完成——当前目标、以及同一条路线里就在附近的其他目标会一起标上，不用你一个个动手。它只会标记**采集物**和**敌人**这两类每天会刷新的点位，**收集物永远不会被自动标记**。
- 这些自动打的勾**每天凌晨四点自动清空**（游戏服务器也是这个点把采集物和敌人补满），所以你不需要手动取消完成标记；第二天载入同一条路线就能重新走一遍。
- 开关**记在路线自己身上**：你把一条路线当刷怪路线用（打开开关），它就会随路线一起保存；以后每次载入这条路线，开关自动是开着的。退出导航时开关会关闭，不会影响别的路线。
- 这些标记**不会同步到库街区**（上传和下载都不参与），所以在库街区那边的进度不会被这类点位搅乱。
- 触发范围可以在 设置 →「操作优化」里单独调（「刷怪采集自动标记范围 · 像素」，默认 30）。嫌容易误触就调小，嫌不够灵敏就调大。
- 修复：星炬学院这类"开放分层地图"里的收集物此前不显示。分层地图现在分**开放**（本身不封闭、无限定出入口、地表也算一层）和**封闭**（洞穴、地下的遗迹、建筑内部）两种，站在开放分层的地表上时，不再隐藏没有层级属性的点位；封闭分层维持原样。全游戏现在只有星炬学院属于开放分层。
- 修复：旧版本遗留的点位记录可能有一部分散落在别处（例如删除记录本时被移走的副本）。现在这些记录会被重新找回来，并**逐行**列在「本地点位记录本」里，你可以自己勾选哪些要恢复；恢复前不会替你改动任何东西。
- 修复：给记录本换绑库街区账号时，会先确认再清掉这本记录本的云端基线，本地点位一个都不会少；扩展弹窗里打印的账号 ID 现在可以直接粘贴，程序会自己去掉前缀。
- 更新体验：填了 Mirror酱 CDK 时程序更新真的会走镜像了（此前增量包"下载了却没被用上"，分片仍旧整包从 GitHub 重下）；更新卡片现在固定两行显示「下载来源」和「正在进行」，并带真实字节进度；连不上 GitHub 时也能完成更新（自动改用 Mirror酱 的完整程序包继续）。更新日志 `Logs/resource-updates.log` 会写明这次程序包来自哪里。
