# 黑海岸不可探测点位小样本核验

2026-10-29，在 `codex/marker-detectability` 分支上，以 `eab43c8` 为基线进行离线实验。视频中的三个收集目标均已通过地图候选、库街区说明及触发前后攻略图片交叉确认。**这是半自动可行性样本，不是全自动准确率测试，也未接入运行时。**

用户确定的定义：正常使用探测仪查漏会漏掉的点位，包括采集、机关、解谜或破坏障碍前无法探测，触发后才出现或可被探测的目标。未命中补充清单的点位仍为未知。

## 自动部分与人工部分

人工确定视频分段、关键帧、场景与大地图玩家中心，自动部分为 SIFT 特征、比例检验、RANSAC 相似变换拟合、坐标换算和附近宝箱候选排序。使用本机已有 OpenCV 5.0.0 SIFT；本次没有调用产品的 SURF 定位器。最终图文交叉核验由代理完成，不要求用户逐点确认。

### 大地图

选取 9、27、30、33、69 秒五帧。自动配准内点数分别为 **139、159、209、223、362**，半尺寸瓦片拼图中的中位拟合残差为 **0.23–0.31 像素**。这是图像配准残差，不能解释为宝箱位置误差。

复用工程 `tools/KuroMapFeatureBuilder/main.cpp` 的坐标约定：瓦片文件名的 Y 索引与图像向下的像素 Y 相反，拼图按 `maxTileY - tileY` 排列。原始点位坐标先除以100；没有改动工程坐标代码或标定。

9秒的玩家位于出发位置，最近宝箱是另一处 `1290397955877834752`；不能据此把本段属性贴过去。收集后的27秒定位，目标点距离约3.7游戏坐标单位，第二候选约34.3单位。玩家中心由人工取 `(422,240)`，存在像素取点误差。

### 小地图

九帧正向样本：21、24、60、63、66、105、108、111、114秒。固定圆形裁剪，遮住中心玩家箭头；比例检验0.7，RANSAC阈值2像素。预设几何门槛为至少12内点、内点比例至少0.5、中位残差小于2像素。该门槛仅为实验筛选，不等价于产品完整几何门禁。

- 第二段60/63/66秒通过门槛，分别14/14/13内点。
- 第一段21/24秒各只有3内点，拒绝单独依赖小地图；由27秒大地图及攻略核验补足。
- 第三段105/108/111/114秒为8/11/7/10内点，均未过门槛。四帧最近候选一致，只作为线索；不为通过实验而降低门槛。
- 错场景对照：24秒强制匹配900，63与114秒强制匹配8，三次全部被拒绝。样本太少，不代表已测得误报率。

第二段有现实歧义：`1290424637294469120` 是附近高处精密箱，其平面位置距目标仅约2.39游戏坐标单位。69秒大地图定位下，两者距离玩家约5.3和6.1单位，不能凭最近点自动裁决；库街区“爬到顶上”与“河流旁打破石头”、视频中的箱子类别和环境可排除前者。
