# 大地图手柄光标点位修复

## 原因与操作

此前 RB 独立助手只有当前路线目标和打开大地图前玩家位置的附近列表，没有连接游戏白色圆环光标与实际地图标记。因此移动地图对准其他标记时，助手仍可能显示没有可查看点位。这属于手柄适配缺失。

现在的操作为：**游戏白色光标圈对准标记 → RB → 左摇杆／方向键选择 → A 查看攻略 → 详情页按住 X 约 0.6 秒，完成当前点**。B 逐级返回。圈内有多个重叠标记时分别列出，只完成明确选中的一个点。

光标圈内的未完成点优先显示，不受大世界的附近距离限制。路线目标和开图前附近列表仍作为独立备选，与光标候选去重。大世界快捷键保持 LB+B 完成、LB+X 附近攻略。

## 实现边界

- 从实际游戏客户区截图识别白色圆环，不使用系统鼠标位置或屏幕中心回退。未检测到、遮挡或多个同样可信的圆环时提示重试。
- 候选来自原生覆盖层实际绘制的图标、折叠组成员及展开列表位置，遵循当前筛选和完成状态。工具面板覆盖处不作为可见候选。
- 图像与绘制几何配对发布；截图检测只在读取或确认候选时执行，不占用每帧渲染流程。连续新帧和轻微定位抖动不会单独使同一批点失效。
- 按 A 时重新读取新鲜画面，核对档案、场景、窗口及进程、筛选、候选修订和明确点位身份。失效时拒绝，不自动改成路线目标或其他点。
- 助手会话及前台窗口身份经过核验，取消后迟到的回复不能重新打开攻略。列表名称异步更新时按完整点位身份保留选择。
- 详情打开后沿用现有单点完成与保存流程，不要求阅读期间一直保持原光标画面。
