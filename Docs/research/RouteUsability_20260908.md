# 路线退出、删除与快捷键指南

## 新入口

- **退出导航**：功能页和游戏大地图路线工具条都提供入口。立即隐藏自动路线并取消活动路线恢复；保存的路线文件和点位完成记录保留。
- **删除选中路线**：在功能页的已保存路线列表中选择一条，点击删除并在应用内核对名称。删除活动路线时同时退出导航；其它路线和点位完成记录保留。
- **查看当前目标攻略**：功能页和大地图路线工具条提供按钮。游戏在前台且存在活动路线当前目标时，默认按 **F8** 打开攻略浮窗，再按一次关闭；浮窗自身获得焦点时也可按同一键关闭。打开或关闭攻略不会完成目标或推进顺序。
- **攻略浮窗完成点位**：浮窗不显示系统标题栏，保留窗口内关闭入口。浮窗获得焦点时，默认按 **Z** 只标记当前展示的点完成，保存成功后自动关闭，保存失败则保留窗口并提示。完成键不会撤销已有完成记录；游戏获得焦点时仍执行小地图附近点规则。
- **使用指南**：WinUI 左侧新增入口，介绍普通点位攻略、自动路线流程、退出与删除，以及快捷键设置。功能页也有指南入口。

## 快捷键

| 默认键 | 操作 | 条件 |
| --- | --- | --- |
| Z | 完成附近点；多个候选时先选择 | 游戏前台，小地图定位有效 |
| Z | 完成浮窗当前点，保存成功后关闭 | 攻略浮窗获得焦点；失败时保留 |
| Q | 记录手绘线段的两个端点 | 游戏前台，大地图定位有效，未处于自动路线选点 |
| F8 | 打开当前目标攻略，再按关闭 | 游戏前台打开时需要活动路线当前目标；浮窗获得焦点时也可关闭 |
| Shift + 左键拖拽 | 临时矩形框选 | 自动路线选点时 |
| Esc | 取消当前手势，否则返回移动地图 | 大地图规划交互有效时 |

Z、Q、F8 三个绑定可在「使用指南 → 快捷键与自定义」更改、禁用或恢复默认，保存后即时应用并随配置恢复。完成键的两种行为按焦点区分，使用同一个绑定。指南、功能页和覆盖层提示显示实际配置。只接受不重复的单个字母、数字或功能键；M 用于地图状态辅助，F10 用于诊断截图，保留不可绑定。Ctrl、Alt、Shift、Win 组合不会触发这些自定义操作。更换绑定时不会把已经按住的键当成新按下。

普通点位仍可在退出选点后，直接左键点击游戏大地图的具体标记查看攻略；重叠标记先展开再选一个。普通右键切换该点完成状态。

## 状态与保存

「暂停」保留活动路线及大地图静态连线，便于稍后继续；「退出选点」仅结束选点；「退出导航」会结束当前路线显示。退出后仍可从保存列表重新加载。

绘制时重新核对活动路线 ID，退出或替换路线后，即使定位线程仍保留旧帧，也不会继续画出旧连线。暂停会立即停止小地图动态指引。

退出先原子保存空的活动指针，再更新内存。删除先在同目录重命名目标文件，再清除匹配的活动指针；指针写入失败时回滚，文件被占用时报告失败。损坏的路线文件可以单独删除。完成状态继续使用原有本地记录。
