# 2026.9.17.4 更新状态修复

本版本只修复一件事：部分玩家点击「检查更新」时出现「拒绝旧清单或同一清单序号下的不同内容」而无法更新。

- **按发布渠道记录更新序号**：程序改为按发布密钥分别记录各渠道已验证过的最高清单序号与内容摘要。本地测试/预览渠道不再影响正式渠道；同一序号下的重新发布、以及维护者重置渠道序号后序号变小，都会自动重新同步记录并在界面上说明，不再让客户端永久卡住。
- **回放旧清单仍然拒绝**：清单所属程序版本早于当前运行版本时继续拒绝；已安装资源、离线导入的单调性与不可变校验不变。
- **设置新增「修复更新状态」**：仅在该类拒绝出现后显示，用内置公钥重新验证当前线上清单并据此重建本机记录；该动作会写入 `%LOCALAPPDATA%\IMao-WinUI\Logs\resource-updates.log`。
- **发布侧禁止序号重用**：最高已发布序号记录在 `updates/channel-state.json`，发布脚本在推进稳定清单之前核对并先写入；回退或重写历史都不会让旧序号重新可用。
- **已经卡住的旧版本用户**：完全退出软件后删除 `%LOCALAPPDATA%\IMao-WinUI\ResourceUpdates\update-state.json`，再打开即可正常检查更新。该文件只保存防回退与自动检查记录，点位进度、路线与个人设置不受影响。
