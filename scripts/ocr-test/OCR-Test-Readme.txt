旧电脑定位测试包（107）

设置 → 性能优化 → GPU 加速（OCR 坐标识别）。保存后，从托盘完全退出，再重新打开 IMao。
设置页和诊断页显示实际后端；请求 GPU 不代表一定启用成功，失败会回退 CPU 并显示原因。
未曾保存该选项时，普通启动默认 CPU，Start-CPU.cmd / Start-GPU.cmd 仍可选择测试后端。
一旦在设置页保存过选择，设置优先于启动脚本。后续对照测试请使用设置页切换。
脚本显卡编号默认 0，Start-GPU.cmd 1 等可指定编号。
SURF 和楼层分类仍由 CPU 计算，GPU 开关仅用于 OCR。

建议同一场景分别测试 CPU 和 GPU，各正常跑图一分钟，再切换大小地图、失焦并返回。
本轮无须开启完整诊断录制。反馈普通 Logs 文件夹，并注明模式、时间和标记滞后情况。
启动脚本会请求管理员授权；取消授权时会报错。
差异包使用方式以 _test-delta/README.txt 为准，切勿覆盖玩家安装目录。
